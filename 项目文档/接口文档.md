# 智教魔方 API 接口文档

## 基础信息

### 服务地址

```http
http://<server>:8000/api
```

### 认证方式

除登录接口外，其余接口均需在请求头中携带：

```http
X-Session-ID: <session_id>
```

---

# 1 用户认证模块

## 1.1 用户登录

### 请求

```http
POST /api/login
```

### Request Body

```json
{
  "username": "admin",
  "password": "123456"
}
```

### Response

```json
{
  "status": "success",
  "message": "登录成功",
  "session_id": "xxxx-xxxx"
}
```

---

## 1.2 获取当前用户信息

### 请求

```http
GET /api/getUserInfo
```

### Header

```http
X-Session-ID: session_id
```

### Response

```json
{
  "userId": 1,
  "userName": "teacher1",
  "userRole": "teacher"
}
```

---

## 1.3 用户注销

### 请求

```http
POST /api/logout
```

### Header

```http
X-Session-ID: session_id
```

# 2 班级管理模块

## 2.1 教师创建班级

```http
POST /api/teacher/classes
```

### Request Body

```json
{
  "name": "软件工程2201",
  "description": "软件工程专业班级"
}
```

### Response

```json
{
  "id": "uuid",
  "name": "软件工程2201",
  "class_code": "ABC123",
  "teacher_id": 2,
  "status": "active"
}
```

---

## 2.2 获取教师班级列表

```http
GET /api/teacher/classes
```

---

## 2.3 获取班级详情

```http
GET /api/teacher/classes/{class_id}
```

返回班级信息及学生列表。

---

## 2.4 解散班级

```http
POST /api/teacher/classes/{class_id}/dissolve
```

---

## 2.5 移除学生

```http
DELETE /api/teacher/classes/{class_id}/members/{student_id}
```

---

## 2.6 学生加入班级

```http
POST /api/student/classes/join
```

### Request Body

```json
{
  "class_code": "ABC123"
}
```

---

## 2.7 学生班级列表

```http
GET /api/student/classes
```

---

## 2.8 学生退出班级

```http
POST /api/student/classes/{class_id}/leave
```


```json

  "role": "teacher"
```
