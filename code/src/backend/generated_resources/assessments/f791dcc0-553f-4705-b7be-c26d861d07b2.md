题目1:  
点亮一个LED灯并使其亮暗闪烁。  
参考答案1:  
```python
import RPi.GPIO as GPIO

# 设置GPIO模式为BCM编号  
GPIO.setmode(GPIO.BCM)

# 定义LED的GPIO引脚编号  
led_pin = 21  

# 设置引脚为输出模式  
GPIO.setup(led_pin, GPIO.OUT)  

# 设置引脚为高电平（亮）  
GPIO.output(led_pin, GPIO.HIGH)  

# 闪烁LED  
while True:  
    GPIO.output(led_pin, GPIO.HIGH)  
    time.sleep(0.1)  
    GPIO.output(led_pin, GPIO.LOW)  
    time.sleep(0.1)
```  
代码解释:  
1. 导入RPi.GPIO库，设置模式为BCM编号，确保GPIO引脚编号正确。  
2. 定义LED的引脚编号为21，并将其设置为输出模式。  
3. 通过循环点亮LED（高电平）并稍后关闭（低电平），实现亮暗闪烁效果。  
错误处理建议: 若未正确设置引脚编号，可能导致GPIO未初始化或输出无效。需确保`GPIO.setup(led_pin, GPIO.OUT)`正确。
