题目1: 控制树莓派GPIO引脚输出LED灯并实现亮暗切换  
参考答案1:  
```python
import RPi.GPIO as GPIO  
import time  

# 定义GPIO引脚（BCM编号）  
GPIO.setmode(GPIO.BCM)  
GPIO.setup(21, GPIO.OUT)  # 设置GPIO21为输出模式  

# 设置输出为高电平  
GPIO.output(21, GPIO.HIGH)  

# 控制LED亮暗切换  
while True:  
    time.sleep(1)  
    GPIO.output(21, GPIO.LOW)  
    time.sleep(1)  
```  
代码解释: 本程序使用树莓派的GPIO21引脚控制LED灯，通过循环实现亮暗切换。首先导入Raspberry Pi的GPIO库，设置模式为BCM编号。设置引脚为输出模式后，循环读取时间，每1秒切换状态。错误处理建议：确保GPIO21引脚未被占用，且未与其他设备冲突。  

题目2: 测试GPIO引脚的输出状态  
参考答案2:  
```python  
# 获取GPIO引脚信息  
GPIO.setmode(GPIO.BCM)  
GPIO.setup(21, GPIO.OUT)  

# 输出状态  
print(GPIO.output(21))  
```  
代码解释: 本程序通过调用GPIO的output函数测试GPIO21引脚的输出状态。输出结果为1表示高电平，0表示低电平。错误处理建议：检查GPIO是否被占用，确保没有其他程序同时使用该引脚。
