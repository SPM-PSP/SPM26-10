题目2: [题目内容]  
题目内容：在嵌入式系统中，设备驱动模型需处理异步事件，以下哪种方法最常见？  
参考答案2: [参考答案内容]  
参考答案内容：设备驱动模型通常使用异步事件处理机制，确保系统能够及时响应外部事件。  

[编程题：  
```cpp  
#include <pthread.h>  
#include <stdio.h>  

// 示例代码  
pthread_mutex_t mutex;  
int event_id = 0;  

void* event_handler(void* arg) {  
    printf("Event received.\n");  
    event_id++;  
    return NULL;  
}  

int main() {  
    pthread_mutex_init(&mutex);  
    pthread_mutex_lock(&mutex);  
    int result = pthread_create(&event_id, NULL, event_handler, NULL);  
    if (result != 0) {  
        perror("Thread creation failed");  
        return 1;  
    }  
    pthread_mutex_unlock(&mutex);  
    return 0;  
}  
```
