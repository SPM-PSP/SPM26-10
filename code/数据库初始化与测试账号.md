# 数据库初始化与测试账号

本文档提供本项目最基本的 MySQL 初始化命令，包括：

- 创建业务数据库 `educational_platform`
- 切换到目标数据库
- 插入 1 个管理员、1 个教师、1 个学生测试账号

## 1. 创建数据库

先登录 MySQL：

```bash
mysql -u root -p
```

然后执行：

```sql
CREATE DATABASE IF NOT EXISTS educational_platform
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

切换到项目数据库：

```sql
USE educational_platform;
```

## 2. 创建表结构

本项目后端启动时会自动检查并创建表结构。

也就是说，在插入测试账号前，建议先运行一次后端：

```bash

```

如果后端启动成功，`users` 等表会自动创建。

你也可以先在 MySQL 中检查：

```sql
SHOW TABLES;
```

确认已经存在 `users` 表后，再执行下面的插入命令。

## 6. 如果重复插入报错

如果之前已经插入过同名用户，执行上述 `INSERT` 可能会报唯一键冲突。

这时可以先检查现有记录：

```sql
SELECT id, username, role
FROM users
WHERE username IN ('admin', 'teacher', 'student');
```

如果你明确要重建这三个测试账号，可以先删除再插入：

```sql
DELETE FROM users
WHERE username IN ('admin', 'teacher', 'student');
```

然后重新执行第 3 节的插入语句。

## 7. `.env.example` 修改指引

### 7.1 先明确两件事

- `.env.example` 是**模板文件**
- 项目实际运行时读取的是根目录下的 `.env`

也就是说：

1. 你可以保留 `.env.example` 作为示例
2. 真正给自己本机使用时，应复制一份为 `.env`

例如：

```bash
cp .env.example .env
```

然后修改 `.env`，不要直接把真实密码和 API Key 长期写死在 `.env.example` 里。

### 7.2 当前 `.env.example` 里最关键的字段

当前模板文件包含这些核心配置：

```env
# 数据库
DATABASE_URL=mysql+aiomysql://root:123456@127.0.0.1:3306/educational_platform

# LLM 模式
LLM_MODE=hybrid

LLM_PROVIDER=deepseek
LLM_API_BASE_URL=https://api.deepseek.com
LLM_API_MODEL=deepseek-v4-flash
LLM_API_KEY=your_deepseek_api

LLM_API_TIMEOUT_SECONDS=120

# Embedding / RAG
EMBEDDING_MODE=local
EMBEDDING_PROVIDER=local
EMBEDDING_API_BASE_URL=
EMBEDDING_API_KEY=
EMBEDDING_API_MODEL=
```

### 7.3 你需要改哪些值

#### 1. 数据库连接

如果你的 MySQL 用户名或密码不是默认值，就改这一行：

```env
DATABASE_URL=mysql+aiomysql://你的用户名:你的密码@127.0.0.1:3306/educational_platform
```

例如：

```env
DATABASE_URL=mysql+aiomysql://root:my_mysql_password@127.0.0.1:3306/educational_platform
```

#### 2. LLM 提供商

如果你继续使用当前较快的 DeepSeek 方案，保持：

```env
LLM_MODE=hybrid
LLM_PROVIDER=deepseek
LLM_API_BASE_URL=https://api.deepseek.com
LLM_API_MODEL=deepseek-v4-flash
LLM_API_KEY=你的 DeepSeek API Key
```

只需要把：

```env
LLM_API_KEY=your_deepseek_api
```

改成你的真实 Key。

#### 3. 如果切回 Qwen / DashScope

把 LLM 部分改成：

```env
LLM_MODE=hybrid
LLM_PROVIDER=dashscope
LLM_API_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_API_MODEL=qwen3.5-flash
LLM_API_KEY=你的阿里云百炼API Key
```

### 7.4 当前推荐的 `.env` 写法

如果你现在本机是：

- MySQL 本地运行
- 数据库名 `educational_platform`
- 使用 DeepSeek API
- 向量检索仍然走本地 Chroma

那么推荐 `.env` 内容如下：

```env
DATABASE_URL=mysql+aiomysql://root:你的MySQL密码@127.0.0.1:3306/educational_platform

LLM_MODE=hybrid
LLM_PROVIDER=deepseek
LLM_API_BASE_URL=https://api.deepseek.com
LLM_API_MODEL=deepseek-v4-flash

EMBEDDING_MODE=local
EMBEDDING_PROVIDER=local
EMBEDDING_API_BASE_URL=
EMBEDDING_API_KEY=
EMBEDDING_API_MODEL=
```
