# 网络性能分析与拥塞控制

## 1. 网络性能指标回顾
衡量网络性能常见指标包括：
- 带宽
- 吞吐量
- 时延
- 抖动
- 丢包率
- 利用率

## 2. 时延的组成
网络中的总时延通常由以下部分构成：
- 发送时延
- 传播时延
- 处理时延
- 排队时延

## 3. 发送时延与传播时延区别
- 发送时延：把数据推入链路所需时间
- 传播时延：信号在介质中传播所需时间

## 4. 时延带宽积
时延带宽积表示在链路上传播中的比特数量，是分析高带宽长距离链路的重要概念。

## 5. 吞吐量与带宽
- 带宽是理论上限
- 吞吐量是实际达到的速率

吞吐量通常受多种瓶颈约束，不一定接近带宽上限。

## 6. 拥塞的含义
当网络中分组数量过多，导致路由器缓存积压、排队时延增大甚至丢包时，就发生了拥塞。

## 7. 拥塞形成原因
- 输入负载过高
- 链路带宽有限
- 路由器缓存有限
- 路由选择不合理

## 8. 拥塞控制与流量控制区别
- 流量控制：协调发送方和接收方速度
- 拥塞控制：防止整个网络进入过载状态

## 9. TCP 拥塞控制机制
### 慢开始
连接初期逐步探测可用带宽。

### 拥塞避免
达到阈值后更平缓地增长发送速率。

### 快重传
收到多个重复确认后，不等待超时直接重传。

### 快恢复
在发生轻度拥塞后更快恢复传输速率。

## 10. 排队管理与主动丢包
某些网络设备会通过主动队列管理机制在缓存即将溢出前提前丢弃分组，以降低全局拥塞程度。

## 11. 性能分析常见题
- 某链路的发送时延怎么计算
- 为什么高利用率不一定代表高性能
- 流量控制与拥塞控制有何区别
- 慢开始和拥塞避免如何切换

## 12. 学习建议
性能分析题重在公式理解与过程推导，建议结合数值题练习：
- 计算时延
- 计算吞吐
- 分析 TCP 窗口变化
