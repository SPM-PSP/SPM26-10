# 局域网交换与无线网络

## 1. 局域网概述
局域网通常用于楼宇、校园、实验室、企业内部，具有范围小、速率高、误码率低的特点。

## 2. 以太网
以太网是当前最常见的局域网技术。

### 以太网特点
- 采用分组交换
- 主要基于帧传输
- 使用 MAC 地址标识设备

## 3. MAC 地址
MAC 地址是链路层地址，一般烧录在网卡中。

特点：
- 通常为 48 位
- 本地链路内有效
- 用于交换机转发判断

## 4. 交换机工作原理
交换机根据 MAC 地址表转发帧。

### 基本过程
1. 学习源 MAC 与端口映射
2. 查询目标 MAC
3. 已知则定向转发
4. 未知则泛洪

## 5. 冲突域与广播域
- 集线器会扩大冲突域
- 交换机可隔离冲突域
- 路由器可隔离广播域

## 6. VLAN
虚拟局域网用于把一个物理局域网划分成多个逻辑广播域。

优点：
- 提高安全性
- 减少广播范围
- 便于管理

## 7. STP 生成树协议
在交换网络中为了避免环路，可使用生成树协议阻塞部分链路。

目的：
- 避免广播风暴
- 防止 MAC 表震荡

## 8. 无线局域网
无线局域网常采用 IEEE 802.11 标准。

组成要素：
- 终端设备
- 无线接入点 AP
- 无线信道

## 9. 无线网络特点
- 移动性强
- 部署灵活
- 易受干扰
- 安全风险相对更高

## 10. 无线网络中的介质访问
无线中通常使用 CSMA/CA，而不是 CSMA/CD。

原因：
- 无法像有线共享总线那样方便检测冲突

## 11. 常见无线安全机制
- WEP
- WPA
- WPA2
- WPA3

## 12. 复习重点
- 交换机和路由器区别
- MAC 地址与 IP 地址区别
- 冲突域和广播域区别
- VLAN 的作用
- 无线网络为什么采用 CSMA/CA
