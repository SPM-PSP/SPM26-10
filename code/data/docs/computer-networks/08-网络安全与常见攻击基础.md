# 网络安全与常见攻击基础

## 1. 网络安全目标
网络安全通常围绕三个核心目标展开：
- 机密性
- 完整性
- 可用性

此外还包括身份认证和不可否认性。

## 2. 加密基础
### 对称加密
加密和解密使用同一把密钥。

特点：
- 速度快
- 密钥分发困难

### 非对称加密
加密和解密使用公钥、私钥对。

特点：
- 便于密钥管理
- 计算开销较大

## 3. 数字签名
数字签名用于证明消息确实来自某发送者，并且传输中未被篡改。

## 4. 哈希与摘要
哈希函数可将任意长度数据映射为固定长度摘要，常用于完整性校验。

## 5. TLS/SSL
TLS 用于在应用层之下提供安全通信能力，常见于 HTTPS。

## 6. 防火墙
防火墙根据安全策略对进出网络的数据流进行过滤和控制。

常见类型：
- 包过滤防火墙
- 状态检测防火墙
- 应用层网关

## 7. 入侵检测与入侵防御
- IDS：发现可疑行为并告警
- IPS：发现后可主动拦截

## 8. 常见攻击方式
### DoS 与 DDoS
通过大量无效请求耗尽系统资源。

### SQL 注入
向应用输入恶意 SQL 语句。

### XSS
跨站脚本攻击，向网页注入恶意脚本。

### ARP 欺骗
伪造 ARP 报文，扰乱局域网中的地址解析关系。

### 中间人攻击
攻击者位于通信双方之间窃听或篡改数据。

## 9. 常见防护措施
- 强密码与多因素认证
- 最小权限原则
- 数据加密
- 访问控制
- 日志审计
- 定期更新和补丁管理

## 10. 学习重点
- HTTPS 为什么更安全
- 数字签名与加密区别
- 常见攻击类型及基本原理
- 防火墙与 IDS/IPS 区别
