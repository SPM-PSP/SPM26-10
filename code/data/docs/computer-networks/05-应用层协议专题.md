# 应用层协议专题

## 1. 应用层概述
应用层直接为用户应用程序提供网络服务，是最贴近用户的一层。

## 2. DNS
DNS 的作用是将域名解析为 IP 地址。

### 特点
- 采用分布式层次结构
- 常用 UDP 传输
- 也可能使用 TCP

### 查询方式
- 递归查询
- 迭代查询

## 3. HTTP
HTTP 是超文本传输协议，是 Web 的基础协议。

### 特点
- 客户端/服务器模式
- 无状态
- 请求/响应方式

### 常见方法
- GET
- POST
- PUT
- DELETE

### 常见状态码
- 200：成功
- 301：永久重定向
- 302：临时重定向
- 404：资源不存在
- 500：服务器内部错误

## 4. HTTPS
HTTPS 是在 HTTP 基础上加入 TLS/SSL 安全机制。

作用：
- 加密
- 身份认证
- 数据完整性保护

## 5. FTP
FTP 用于文件传输。

特点：
- 使用两个连接
- 控制连接通常用 21 端口
- 数据连接可主动或被动建立

## 6. SMTP 与邮件系统
SMTP 用于发送电子邮件。

邮件系统常涉及：
- SMTP：发送
- POP3：下载邮件
- IMAP：远程管理邮件

## 7. DHCP
DHCP 用于动态分配 IP 地址及相关网络参数。

基本流程常记作：
- Discover
- Offer
- Request
- Acknowledge

## 8. WebSocket 与传统 HTTP
WebSocket 适合双向实时通信，而传统 HTTP 更偏向请求/响应。

## 9. 代理与缓存
应用层常结合代理服务器和缓存服务器提高访问效率。

常见作用：
- 缓解源站压力
- 降低时延
- 提高可扩展性

## 10. CDN
内容分发网络通过将内容部署到靠近用户的位置来提高访问性能。

## 11. 常见考点
- DNS 为什么常用 UDP
- HTTP 和 HTTPS 区别
- FTP 为什么要两个连接
- SMTP、POP3、IMAP 的作用区别
- 动态获取 IP 的基本过程
