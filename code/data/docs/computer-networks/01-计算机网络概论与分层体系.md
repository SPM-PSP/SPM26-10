# 计算机网络概论与分层体系

## 1. 计算机网络的定义
计算机网络是由若干独立的计算机、终端设备和通信设备，通过通信链路和网络协议互联而成的系统。它的目标是实现数据通信、资源共享和协同工作。

## 2. 计算机网络的主要功能
- 数据通信：在不同主机之间传输数据。
- 资源共享：共享打印机、文件、数据库和应用服务。
- 分布式处理：多个节点协同完成计算任务。
- 提高可靠性：通过冗余路径和冗余设备降低单点故障风险。
- 支持远程访问：用户可以跨地域访问服务和资源。

## 3. 网络分类
### 按覆盖范围分类
- 局域网 LAN：范围较小，通常用于校园、实验室、企业内部。
- 城域网 MAN：覆盖一座城市或较大区域。
- 广域网 WAN：覆盖跨城市、跨国家甚至全球。

### 按交换方式分类
- 电路交换：通信前先建立专用链路。
- 报文交换：以整个报文为单位转发。
- 分组交换：将数据拆成分组逐跳转发，是现代网络的主流方式。

## 4. 协议与接口
协议规定了通信双方在传输过程中必须遵守的规则，包括语法、语义和同步。

- 语法：数据格式
- 语义：控制信息含义
- 同步：发送与接收时序

接口描述相邻层之间如何交互，服务描述下一层向上一层提供什么能力。

## 5. 分层思想
网络分层的目的在于降低复杂度。每一层只关心本层任务，并向上层提供服务、调用下层服务。

分层带来的好处：
- 结构清晰
- 便于实现和维护
- 便于标准化
- 某一层变化不会影响所有层

## 6. OSI 七层模型
### 物理层
负责比特流传输，涉及接口标准、信号、电缆和传输介质。

### 数据链路层
负责成帧、差错检测、介质访问控制。

### 网络层
负责逻辑寻址和路由选择。

### 运输层
负责端到端通信，提供可靠或不可靠传输。

### 会话层
负责会话建立、维护和释放。

### 表示层
负责数据格式转换、加密和压缩。

### 应用层
面向用户应用，如 HTTP、FTP、SMTP、DNS。

## 7. TCP/IP 参考模型
TCP/IP 模型通常分为四层：
- 网络接口层
- 网际层
- 运输层
- 应用层

它比 OSI 更贴近实际互联网实现。

## 8. OSI 与 TCP/IP 对比
- OSI 更适合教学与理论分析。
- TCP/IP 更适合实际互联网协议实现。
- TCP/IP 没有严格区分会话层和表示层。

## 9. 网络性能指标
- 带宽：单位时间内可传输的数据量上限。
- 吞吐量：实际达到的数据传输速率。
- 时延：数据从源到宿所需时间。
- 时延带宽积：链路中“正在传输”的比特数。
- 往返时延 RTT：从发送到收到响应的总时间。
- 利用率：信道或设备的忙碌程度。

## 10. 学习建议
学习网络课程时应重点掌握：
- 分层思想
- 常见协议所在层次
- 各层核心功能
- 时延、吞吐、带宽之间的关系
