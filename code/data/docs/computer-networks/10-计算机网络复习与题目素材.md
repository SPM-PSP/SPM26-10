# 计算机网络复习与题目素材

## 1. 课程复习主线
复习计算机网络课程时，建议按以下主线梳理：
- 分层体系
- 物理层与链路层
- 网络层与 IP
- 传输层与 TCP/UDP
- 应用层协议
- 局域网与无线网络
- 网络安全与性能分析

## 2. 高频简答题素材
### 题目 1
为什么要采用分层结构设计网络协议？

参考要点：
- 降低系统复杂度
- 明确各层功能边界
- 便于标准化
- 提高可维护性与可扩展性

### 题目 2
IP 地址与 MAC 地址有什么区别？

参考要点：
- IP 是逻辑地址，面向网络层
- MAC 是物理地址，面向链路层
- IP 用于跨网络寻址
- MAC 用于本链路转发

### 题目 3
TCP 为什么可靠，UDP 为什么快？

参考要点：
- TCP 有连接、确认、重传、排序、流控、拥塞控制
- UDP 头部小、机制少、时延低

## 3. 判断与选择题素材
- 路由器工作在网络层。
- 交换机主要根据 MAC 地址转发数据帧。
- DNS 的主要作用是域名解析。
- HTTPS 在 HTTP 基础上增加了安全机制。
- TCP 是面向连接的协议。

## 4. 计算题素材
### 发送时延
若链路速率为 10 Mbps，数据长度为 1 Mb，则发送时延为：

发送时延 = 数据长度 / 链路速率 = 1 / 10 秒 = 0.1 秒

### 传播时延
若链路长度为 1000 km，信号传播速率为 2×10^8 m/s，则传播时延为：

传播时延 = 10^6 / (2×10^8) = 0.005 秒

## 5. 综合分析题素材
### 题目 1
说明一次访问网页过程中，可能涉及哪些协议和层次。

参考思路：
- 应用层：DNS、HTTP
- 运输层：TCP 或 UDP
- 网络层：IP
- 链路层：以太网或 Wi-Fi

### 题目 2
分析 TCP 三次握手的必要性。

参考思路：
- 确认双方收发能力
- 防止已失效连接请求影响新连接
- 同步初始序号

## 7. 知识图谱式复习框架
### 链路
介质、成帧、CRC、MAC、交换机、VLAN

### 网络
IP、ARP、ICMP、路由、分片、NAT

### 传输
TCP、UDP、端口、握手挥手、流控、拥塞控制

### 应用
DNS、HTTP、HTTPS、FTP、SMTP、DHCP

## 8. 复习提醒
网络课程容易“记概念不成体系”，应尽量从“数据如何从一台主机发到另一台主机”的全流程去理解：
- 应用发起请求
- 运输层封装
- 网络层寻址与路由
- 链路层成帧传输
- 对端逐层解封装并交给应用
