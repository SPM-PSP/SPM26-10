# 路由交换与网络设备综合

## 1. 常见网络设备
网络中常见设备包括：
- 中继器
- 集线器
- 网桥
- 交换机
- 路由器
- 网关

## 2. 各设备工作层次
- 中继器：物理层
- 集线器：物理层
- 网桥：数据链路层
- 交换机：数据链路层
- 路由器：网络层
- 网关：可跨多层协议转换

## 3. 中继器与集线器
二者都工作在物理层，主要作用是放大、整形和转发信号。

局限：
- 不能理解帧和分组
- 不能隔离冲突域

## 4. 网桥与交换机
交换机可以看作多端口网桥，负责根据 MAC 地址转发数据帧。

优势：
- 提高带宽利用率
- 减少冲突
- 支持更多端口

## 5. 路由器
路由器根据 IP 地址和路由表转发分组，是连接不同网络的重要设备。

作用：
- 连接异构网络
- 路由选择
- 广播隔离

## 6. 网关
网关常用于协议转换。它不仅仅是简单转发设备，还可能进行数据格式、协议栈甚至应用层逻辑转换。

## 7. 默认网关
默认网关是主机在目标不在本地子网时转发分组的出口路由器地址。

## 8. NAT
网络地址转换用于将私网地址映射为公网地址。

作用：
- 节约公网地址
- 隐藏内网结构

局限：
- 影响端到端透明性

## 9. 负载均衡与反向代理
现代网络系统中常通过负载均衡设备分发请求，提高系统吞吐和可用性。

## 10. 常见综合题
- 交换机和路由器的主要区别
- 哪类设备能隔离广播域
- NAT 的作用和问题
- 默认网关是什么
- 为什么说交换机本质上是多端口网桥
