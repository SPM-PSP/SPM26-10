# 磁盘调度与存储管理

## 1. 磁盘访问特点

相较于 CPU 和内存，磁盘访问速度更慢，因此操作系统需要尽量优化磁盘 I/O。

传统机械磁盘访问延迟通常来自三部分：

- 寻道时间
- 旋转延迟
- 数据传输时间

## 2. 磁盘调度的目标

磁盘调度主要希望：

- 缩短平均寻道时间
- 提高吞吐量
- 减少响应时间
- 保证请求处理相对公平

## 3. 常见磁盘调度算法

### FCFS

按请求到达顺序服务。

优点：

- 简单、公平

缺点：

- 平均寻道时间可能较差

### SSTF

优先处理距离当前磁头最近的请求。

优点：

- 平均寻道性能通常较好

缺点：

- 远处请求可能饥饿

### SCAN

也叫电梯算法。磁头沿一个方向移动，处理沿途请求，到边界后再反向。

### C-SCAN

只在一个方向服务请求，到边界后快速返回起点，再继续同方向扫描。

## 4. 缓冲与缓存

操作系统通常通过缓冲区和缓存减少实际磁盘访问次数。

### 缓冲

主要用于平滑设备与 CPU 的速度差异。

### 缓存

主要用于提高热点数据访问速度。

## 5. 交换空间

交换空间用于支持虚拟内存，把暂时不用的页换出到磁盘。

如果系统频繁使用交换空间，往往意味着：

- 内存压力过大
- 工作集超出物理内存容量

## 6. 文件分配方式

常见文件分配方式包括：

- 连续分配
- 链式分配
- 索引分配

## 7. 常见面试问答

### 问：为什么电梯算法通常优于 FCFS？

答：因为它减少了磁头大范围来回移动，从而降低平均寻道开销。

### 问：缓存和缓冲有什么区别？

答：缓存更强调“减少重复访问成本”，缓冲更强调“协调不同速度设备之间的数据传输”。

### 问：为什么 SSD 时代传统磁盘调度思路的重要性有所下降？

答：因为 SSD 没有机械寻道和旋转延迟，随机访问代价远低于机械磁盘。
