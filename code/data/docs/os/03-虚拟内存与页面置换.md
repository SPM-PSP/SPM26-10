# 虚拟内存与页面置换

## 1. 什么是虚拟内存

虚拟内存是一种让程序看到的地址空间大于实际物理内存的技术。

核心思想是：

- 并不是程序所有页面都要同时装入内存
- 当前用到的页面才放进物理内存
- 暂时不用的页面可以留在磁盘或交换区

## 2. 虚拟内存的意义

虚拟内存带来的好处包括：

- 支持更大的程序运行
- 提高内存利用率
- 支持多道程序并发
- 通过按需装入减少启动时的内存压力

## 3. 局部性原理

虚拟内存得以高效工作，依赖程序访问的局部性原理。

### 时间局部性

刚访问过的数据很可能再次访问。

### 空间局部性

访问某个地址后，附近地址也更可能被访问。

## 4. 缺页异常

当进程访问某个虚拟页，而该页当前不在内存中时，会触发缺页异常。

典型处理过程：

1. CPU 发现目标页不存在
2. 触发缺页异常
3. 操作系统查找该页所在外存位置
4. 若内存已满，则选择某页淘汰
5. 将所需页调入内存
6. 更新页表
7. 重新执行导致缺页的指令

## 5. 页面置换

当物理内存没有空闲页框时，需要选择一个旧页淘汰，这就是页面置换。

常见页面置换算法包括：

- FIFO
- LRU
- Clock
- 最优算法 OPT

## 6. 几种常见算法

### FIFO

先进入内存的页先淘汰。

优点：

- 实现简单

缺点：

- 可能出现 Belady 异常

### LRU

淘汰最近最久未使用的页。

优点：

- 更符合局部性原理

缺点：

- 精确实现成本较高

### Clock

使用访问位近似 LRU。

优点：

- 实现效率和效果平衡较好

## 7. 抖动现象

如果系统把大部分时间都用在页面换入换出，而不是执行有效计算，就会出现抖动。

抖动通常说明：

- 可用物理内存不足
- 并发进程过多
- 页面分配策略不合理

## 8. 常见面试问答

### 问：虚拟内存是不是“凭空扩大了物理内存”？

答：不是。它是通过磁盘和地址映射机制，让程序看起来拥有更大的连续地址空间。

### 问：为什么缺页处理会比较慢？

答：因为可能涉及磁盘 I/O，而磁盘速度远慢于内存。

### 问：LRU 为什么常被认为更合理？

答：因为它利用了时间局部性假设，认为近期使用过的页面短时间内更可能再次使用。
