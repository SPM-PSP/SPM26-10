# 操作系统基本概念与系统调用

## 1. 什么是操作系统

操作系统是管理计算机硬件和软件资源、为应用程序提供运行环境的系统软件。

它处于硬件和应用程序之间，承担“资源管理者”和“服务提供者”两类角色。

### 资源管理者

操作系统需要统一管理：

- 处理器
- 内存
- 外设
- 文件
- 网络资源

### 服务提供者

操作系统向上为应用程序提供：

- 进程与线程管理
- 文件系统接口
- 设备访问接口
- 网络通信接口
- 安全与权限控制

## 2. 操作系统的主要目标

操作系统通常希望实现以下目标：

- 方便用户和程序使用计算机
- 提高资源利用率
- 提高系统吞吐量
- 保证公平性和响应性
- 保证安全性与稳定性

## 3. 内核与用户程序

操作系统核心部分称为内核。内核直接运行在高权限级别，负责执行受保护操作，例如：

- 调度 CPU
- 管理内存
- 控制设备
- 处理中断和异常

普通应用程序运行在用户态，不能直接访问硬件，也不能直接执行高权限指令。

## 4. 系统调用的作用

系统调用是用户程序请求操作系统服务的标准入口。

应用程序不能直接访问内核内部功能，而要通过系统调用切换到内核态完成操作。

常见系统调用类型包括：

- 进程控制：`fork`、`exec`、`exit`、`wait`
- 文件操作：`open`、`read`、`write`、`close`
- 设备控制：`ioctl`
- 内存管理：`mmap`、`brk`
- 网络通信：`socket`、`bind`、`connect`

## 5. 系统调用流程

一个简化的系统调用流程如下：

1. 用户程序准备参数
2. 执行陷入指令
3. CPU 从用户态切换到内核态
4. 内核根据系统调用号分派处理函数
5. 内核完成相关操作
6. 返回结果给用户程序
7. CPU 回到用户态继续执行

## 6. 中断、异常与系统调用的关系

三者都可能导致 CPU 从用户态进入内核态，但触发原因不同：

- 中断：通常由外部设备触发
- 异常：通常由程序执行错误或特殊条件触发
- 系统调用：由程序主动发起，属于受控进入内核

## 7. 操作系统常见结构

### 单体内核

大部分核心功能都在内核中，例如 Linux。

优点：

- 性能较高

缺点：

- 模块间耦合较强

### 微内核

尽量把功能放到用户态服务中，内核只保留最基础能力。

优点：

- 模块隔离更强

缺点：

- 通信开销通常更大

## 8. 常见面试问答

### 问：为什么不能让应用程序直接访问硬件？

答：因为这样会破坏系统安全性与资源隔离，程序可能误操作硬件或互相干扰。

### 问：系统调用和普通函数调用有什么区别？

答：系统调用会触发用户态到内核态切换，而普通函数调用通常只是在同一执行态内跳转。

### 问：操作系统最核心的两类任务是什么？

答：一类是资源管理，另一类是为上层程序提供统一服务接口。
