# 并发一致性与经典同步问题

## 1. 并发带来的问题

多个线程或进程同时执行时，如果访问共享资源，就可能产生并发一致性问题。

典型问题包括：

- 丢失更新
- 读到中间状态
- 不可重复结果
- 数据结构损坏

## 2. 临界区

临界区是访问共享资源的那段代码。

对临界区的正确管理目标通常包括：

- 互斥进入
- 有限等待
- 空闲让进

## 3. 常见同步原语

### 互斥锁

保证同一时刻只有一个执行流进入临界区。

### 信号量

可以表示资源数量，也可用于同步事件顺序。

### 条件变量

用于线程之间等待某个条件成立。

### 屏障

用于多个线程在某一阶段同步汇合。

## 4. 生产者-消费者问题

这是经典同步问题之一。

核心约束：

- 缓冲区满时，生产者不能继续放入
- 缓冲区空时，消费者不能继续取出

典型解法会用到：

- 互斥锁
- 计数信号量

## 5. 读者-写者问题

目标是：

- 多个读者可以并发读
- 写者写时必须独占

常见策略：

- 读者优先
- 写者优先
- 公平策略

## 6. 哲学家就餐问题

它展示了多个实体竞争有限资源时如何出现死锁或饥饿。

常见解决思路：

- 限制同时竞争人数
- 资源有序分配
- 引入仲裁者

## 7. 常见面试问答

### 问：互斥和同步有什么区别？

答：互斥强调“同一时刻只能一个进入”，同步强调“按正确顺序协作”。

### 问：为什么只加锁还不一定解决所有问题？

答：因为锁能解决互斥，但不一定能表达执行顺序、条件等待等协作关系。

### 问：为什么生产者-消费者问题常作为教学案例？

答：因为它同时包含互斥、同步和资源计数三个核心概念。
