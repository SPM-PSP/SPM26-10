# 操作系统综合问答与课程复习提纲

## 1. 操作系统复习主线

复习操作系统时，建议按以下主线梳理：

1. 操作系统基本概念
2. 进程与线程
3. CPU 调度
4. 同步与互斥
5. 死锁
6. 内存管理
7. 虚拟内存
8. 文件系统
9. I/O 与设备管理
10. 存储管理与扩展主题

## 2. 高频问题汇总

### 什么是进程，什么是线程？

进程是资源分配的基本单位，线程是 CPU 调度的基本单位。线程共享进程资源，但具有独立执行流。

### 什么是系统调用？

系统调用是用户程序请求操作系统服务的标准接口，也是用户态进入内核态的主要受控途径。

### 什么是上下文切换？

上下文切换是 CPU 在不同任务间切换时保存和恢复执行现场的过程。

### 什么是临界区？

临界区是访问共享资源的关键代码区，必须通过同步机制保证并发安全。

### 什么是死锁？

死锁是多个执行流因资源相互等待而全部无法继续推进的状态。

### 什么是虚拟内存？

虚拟内存通过地址映射和页面换入换出，使程序看到的地址空间大于物理内存。

### 为什么需要页表？

页表用于记录虚拟页到物理页框的映射关系，是实现分页和虚拟内存的关键数据结构。

### `select`、`poll`、`epoll` 有什么区别？

它们都是 I/O 多路复用机制，区别主要在于监听集合管理方式和大规模连接场景下的性能表现。

## 3. 复习时的常见易错点

- 把进程和线程的定义混淆
- 把系统调用、中断、异常混为一谈
- 只记住算法名字，不理解适用场景
- 只记住分页机制，不理解缺页处理流程
- 把缓存、缓冲、交换空间概念混淆

以下问题适合用于教学问答、题目生成和口头抽查：

- 为什么操作系统需要内核态和用户态？
- 线程为什么比进程切换更轻量？
- 时间片轮转适合什么场景？
- 为什么共享内存需要配合同步机制？
- 死锁的四个必要条件是什么？
- 为什么虚拟内存会带来缺页异常？
- 为什么中断处理程序应尽量短小？
- 容器和虚拟机的区别是什么？

## 5. 简答题示例

### 简答题 1

请说明操作系统中进程和线程的区别，并给出适用场景。

### 简答题 2

### 简答题 3

## 6. 论述题示例

### 论述题 1

### 论述题 2

试比较中断、轮询和 DMA 三种 I/O 控制方式的特点及适用场景。
