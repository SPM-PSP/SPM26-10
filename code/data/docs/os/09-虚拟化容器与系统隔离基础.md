# 虚拟化、容器与系统隔离基础

## 1. 为什么需要虚拟化

虚拟化的目标是让一套物理资源被更灵活地使用，从而提升利用率、隔离性和部署效率。

常见收益包括：

- 一机多用
- 更好的环境隔离
- 更快的部署与迁移
- 更方便的测试和运维

## 2. 虚拟机

虚拟机通过虚拟化软件模拟完整硬件平台，使多个操作系统实例能够同时运行。

特点：

- 隔离性较强
- 可以运行不同内核
- 资源开销通常高于容器

## 3. 容器

容器并不是完整虚拟硬件，而是在同一内核之上对进程、文件系统、网络等进行隔离。

特点：

- 启动快
- 资源开销更低
- 与宿主机共享内核

## 4. 容器隔离依赖的基础机制

在 Linux 中，容器隔离常依赖：

- Namespace
- Cgroups

### Namespace

用于隔离：

- 进程视图
- 网络
- 挂载点
- 主机名
- 用户 ID

### Cgroups

用于限制和统计：

- CPU
- 内存
- I/O

## 5. 虚拟化与容器对比

### 虚拟机

- 更像完整计算机
- 隔离更彻底
- 开销更大

### 容器

- 更像受隔离的进程组
- 更轻量
- 共享同一内核

## 6. 常见面试问答

### 问：容器是不是虚拟机？

答：不是。容器通常不虚拟完整硬件，也不自带独立内核，而是共享宿主机内核。

### 问：为什么容器启动通常比虚拟机快？

答：因为容器本质上更接近一组隔离进程，不需要完整启动一个新操作系统。

### 问：容器隔离的关键基础是什么？

答：Linux 中最核心的是 Namespace 和 Cgroups。
