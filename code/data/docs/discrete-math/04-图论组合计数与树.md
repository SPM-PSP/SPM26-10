# 图论组合计数与树

## 1. 图的基本概念
图由顶点和边构成，可分为无向图、有向图、带权图等。

## 2. 图的基本问题
- 连通性
- 路径与回路
- 度
- 子图
- 欧拉图
- 哈密顿图

## 3. 树
树是连通无环图，是计算机科学中最常用的结构之一。学习离散数学中的树，有助于后续理解数据结构和网络拓扑。

## 4. 组合计数
组合计数用于分析方案数和构造数量，常见内容包括：
- 排列
- 组合
- 容斥原理
- 递推关系

## 5. 生成函数与递推初步
某些课程会简要介绍生成函数或递推式求解，用于强化离散结构的表达能力。

## 6. 常见题型
- 判断图的连通性
- 树的性质证明
- 计数问题建模
