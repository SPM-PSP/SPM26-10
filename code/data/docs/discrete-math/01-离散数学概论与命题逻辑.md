# 离散数学概论与命题逻辑

## 1. 离散数学的地位
离散数学是计算机科学的重要理论基础，为数据结构、算法、编译原理、数据库和人工智能等课程提供形式化工具。

## 2. 命题与命题联结词
命题是可以判断真假的陈述句。常见联结词包括：
- 否定
- 合取
- 析取
- 蕴含
- 等价

## 3. 真值表
真值表是分析命题公式真假变化的重要工具。通过枚举所有可能取值，可以判断公式是否为永真式、永假式或可满足式。

## 4. 等值演算
逻辑公式可通过等值变换化简。常见律包括：
- 交换律
- 结合律
- 分配律
- 德摩根律
- 双重否定律

## 5. 主范式
命题公式可化为：
- 主析取范式
- 主合取范式

这是自动推理和逻辑表示的重要基础。

## 6. 学习重点
- 会列真值表
- 会做等值变换
- 会判断逻辑蕴含关系
