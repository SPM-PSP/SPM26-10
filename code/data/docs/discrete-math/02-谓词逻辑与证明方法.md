# 谓词逻辑与证明方法

## 1. 从命题逻辑到谓词逻辑
命题逻辑无法刻画“所有”“存在”这类量化语义，因此需要谓词逻辑。

## 2. 谓词与量词
- 全称量词：对所有对象成立
- 存在量词：存在某个对象成立

谓词逻辑能更精确表达数学和程序性质。

## 3. 量词否定规律
- 否定全称等价于存在否定
- 否定存在等价于全称否定

## 4. 证明方法
常见证明方法包括：
- 直接证明
- 反证法
- 数学归纳法
- 分类讨论

## 5. 数学归纳法
数学归纳法特别适合证明与自然数有关的命题，也是分析递归程序正确性的常见工具。

## 6. 常见考点
- 命题翻译为谓词逻辑公式
- 量词否定化简
- 用归纳法证明递推性质
