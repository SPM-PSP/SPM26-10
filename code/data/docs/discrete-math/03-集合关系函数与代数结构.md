# 集合关系函数与代数结构

## 1. 集合运算
离散数学中常见集合运算包括：
- 并
- 交
- 差
- 补
- 笛卡尔积

## 2. 二元关系
集合上的关系可以分析其性质：
- 自反性
- 对称性
- 反对称性
- 传递性

等价关系和偏序关系是教学重点。

## 3. 等价关系
等价关系满足自反、对称、传递，可把集合划分为若干等价类。

## 4. 偏序关系
偏序关系满足自反、反对称、传递。哈斯图是描述偏序结构的常用工具。

## 5. 函数
函数是特殊关系，学习时重点关注：
- 单射
- 满射
- 双射
- 复合函数
- 逆函数

## 6. 代数结构初步
离散数学还会涉及群、环、域等基础代数结构的入门概念，用于培养抽象建模能力。
