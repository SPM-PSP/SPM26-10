# 语法分析与语法制导翻译

## 1. 语法分析的任务
语法分析器根据文法规则，从 token 序列中识别程序结构，并判断程序是否符合语法规则。

## 2. 上下文无关文法
程序设计语言语法常使用上下文无关文法描述。文法由终结符、非终结符、产生式和开始符号构成。

## 3. 语法树与抽象语法树
- 语法树完整反映推导结构。
- 抽象语法树 AST 去掉了许多中间层和冗余符号，更适合后续语义分析和代码生成。

## 4. 自顶向下分析
自顶向下分析从开始符号出发，试图推出输入串。典型方法包括递归下降分析和 LL(1) 分析。

### LL(1) 文法特征
- 不含左递归
- 要能够进行左因子提取
- 可根据一个向前看符号决定产生式选择

## 5. 自底向上分析
自底向上分析从输入串出发，逐步归约到开始符号。代表方法是 LR 分析。

### 常见 LR 类型
- LR(0)
- SLR(1)
- LR(1)
- LALR(1)

## 6. FIRST 与 FOLLOW 集
这两个集合是构造预测分析表的重要基础：
- FIRST：某符号串可能推出的首终结符集合
- FOLLOW：某非终结符后面可能出现的终结符集合

## 7. 语法制导翻译
在语法分析基础上，可以在产生式上附加语义规则，完成类型检查、中间代码生成和符号表处理等任务。

## 8. 常见考点
- 左递归消除
- FIRST/FOLLOW 求解
- LL(1) 分析表构造
- 移进归约过程分析
- AST 的作用
