# 词法分析与有穷自动机

## 1. 词法分析的任务
词法分析器从源程序字符流中识别单词记号 token，并过滤空白符、注释等无意义字符。它是编译器最前端的入口。

## 2. 常见记号类型
- 关键字
- 标识符
- 常数
- 运算符
- 界符

词法分析的输出通常是 token 序列，每个 token 至少包含类别编码和值或指针信息。

## 3. 正则表达式
正则表达式常用来描述单词的构成规则。典型操作包括：
- 连接
- 并
- 闭包

词法规则往往先写成正则表达式，再转换为自动机实现识别。

## 4. NFA 与 DFA
- NFA：非确定有穷自动机，构造方便。
- DFA：确定有穷自动机，识别效率高。

实际实现中常用“正则表达式 -> NFA -> DFA -> 最小化 DFA”的思路。

## 5. 最长匹配原则
在词法分析中，如果一个输入串可以匹配多个模式，一般采用最长匹配原则，并结合关键字优先于标识符的规则消歧。

## 6. 词法错误处理
词法错误常见于：
- 非法字符
- 标识符格式错误
- 字符串常量未闭合
- 数字常量格式错误

词法分析器通常要尽量报告错误位置，并继续扫描后续内容，以便一次发现更多错误。

## 7. 常见题型
- 写出某类 token 的正则表达式
- 给定正规式构造自动机
- 分析词法分析器如何识别关键字和标识符

## 8. 学习提示
学词法分析时，不要只记定义，要把“形式语言 -> 自动机 -> 扫描程序”这条链路连起来理解。
