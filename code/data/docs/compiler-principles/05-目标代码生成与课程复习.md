# 目标代码生成与课程复习

## 1. 目标代码生成的任务
编译后端需要把中间代码翻译成目标机能够执行的代码形式，同时考虑寄存器分配、指令选择和寻址方式。

## 2. 指令选择
指令选择的目标是用尽量合适的机器指令实现中间表示中的运算。不同指令系统对生成策略影响很大。

## 3. 寄存器分配
寄存器是高价值资源。合理分配寄存器能够显著提升执行效率。

常见思路：
- 活跃变量分析
- 图着色分配
- 简单局部分配策略

## 4. 运行时存储组织
目标代码生成还要考虑：
- 过程活动记录
- 参数传递
- 返回地址保存
- 局部变量与临时变量布局

## 5. 课程复习主线
学完整门课程后，应形成以下主线：
- 字符流如何变成 token
- token 如何被组织成语法结构
- 语义如何附着到语法结构上
- 程序如何被翻译成中间代码
- 中间代码如何优化并映射到目标机

## 6. 高频综合题素材
- 说明编译程序各阶段的输入与输出
- 比较 LL 与 LR 分析方法
- 举例说明局部优化策略
- 解释寄存器分配的重要性

## 7. 教学建议
在知识库中，这类资料既适合问答，也很适合用于生成阶段化试卷：
- 基础概念题
- 文法推导题
- 分析过程题
- 编译流程综合题
