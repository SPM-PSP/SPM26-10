# 编译原理概论

## 1. 编译程序的作用
编译程序的任务是把高级语言源程序翻译成目标程序。目标程序可以是汇编代码、机器代码或中间代码。编译系统不仅要完成翻译，还要检查语法、语义和部分运行时相关问题。

## 2. 编译过程的典型阶段
一个完整编译器通常包括：
- 词法分析
- 语法分析
- 语义分析
- 中间代码生成
- 代码优化
- 目标代码生成

这些阶段既可以严格串行，也可以在工程实现上适度合并。

## 3. 解释器与编译器
- 编译器：先整体翻译，再执行目标代码。
- 解释器：边翻译边执行，不一定产生独立目标程序。

解释执行通常更灵活，编译执行通常效率更高。

## 4. 编译器前端与后端
- 前端：与源语言相关，主要负责分析源程序结构和含义。
- 后端：与目标机相关，负责优化与代码生成。

中间表示 IR 是连接前端和后端的重要桥梁。

## 5. 编译原理课程的核心关注点
这门课程既是理论课，也是系统课。学习重点在于：
- 如何形式化描述程序语言
- 如何自动化识别语言结构
- 如何把语义正确地翻译成可执行形式
- 如何在保证正确性的前提下提升执行效率

## 6. 常见考点
- 编译各阶段的输入输出
- 编译器与解释器区别
- 前端与后端分工
- 中间代码的意义
