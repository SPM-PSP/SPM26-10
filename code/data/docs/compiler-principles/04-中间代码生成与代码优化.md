# 中间代码生成与代码优化

## 1. 为什么需要中间代码
中间代码位于源程序与目标代码之间，便于前后端分离，也有利于跨平台和统一优化。

## 2. 常见中间表示
- 三地址代码
- 四元式
- 逆波兰表示
- 抽象语法树
- 控制流图 CFG

## 3. 三地址代码
三地址代码形式简洁，典型形式包括：
- `x = y op z`
- `x = op y`
- `if x goto L`
- `goto L`

## 4. 基本块与流图
基本块是只有一个入口和一个出口的语句序列。多个基本块之间可构成控制流图，这是局部优化和全局优化的重要基础。

## 5. 常见优化类型
### 局部优化
- 常量折叠
- 公共子表达式消除
- 无用赋值删除

### 全局优化
- 循环优化
- 死代码删除
- 复制传播
- 强度削弱

## 6. 优化目标
优化通常围绕以下目标展开：
- 减少执行时间
- 减少内存占用
- 减少目标代码长度

但优化必须以不改变程序语义为前提。

## 7. 教学价值
这部分内容非常适合出分析题，例如：
- 画基本块
- 构造流图
- 对给定中间代码做局部优化
- 比较不同优化策略的效果
