# 嵌入式 Linux 常见问答汇总

## 1. 什么是 Linux 内核模块

Linux 内核模块是可动态加载和卸载的内核代码。它允许系统在不重新编译整个内核的前提下增加驱动或功能。

## 2. 设备驱动的核心职责是什么

设备驱动负责把操作系统的统一接口转换成对具体硬件的控制逻辑，例如配置寄存器、处理中断、进行数据传输。

## 3. 设备树的本质是什么

设备树本质上是一份硬件描述数据。它告诉内核“板子上有哪些设备、设备挂在哪个总线上、使用哪些资源”。

## 4. 为什么根文件系统很重要

因为内核启动后需要一个最基本的用户态运行环境，根文件系统中包含命令、库、配置和初始化程序。

## 5. `select`、`poll`、`epoll` 的差异

- `select`：早期接口，数量有限制
- `poll`：改进了数量限制问题
- `epoll`：适合高并发和大量描述符场景

## 6. 什么是上下文切换

上下文切换是 CPU 从一个任务切换到另一个任务时保存和恢复执行现场的过程，包括寄存器、程序计数器和栈等信息。

## 7. 为什么中断处理不能太长

因为中断处理时间过长会影响其他任务响应，也可能阻塞后续中断处理，降低系统实时性。

## 8. 共享内存为什么快

因为数据不需要在进程之间来回复制，多个进程可以直接访问同一块物理内存。

## 9. 什么是僵尸进程

僵尸进程是已经退出、但父进程尚未回收其退出状态的子进程。它不会继续运行，但仍占用进程表项。

## 10. 用户态和内核态的主要区别

用户态权限受限，不能直接访问硬件；内核态拥有更高权限，可以调度进程、管理内存、操作设备。

## 11. 嵌入式 Linux 为什么要裁剪

因为嵌入式设备资源有限，不需要桌面系统中大量无关组件，裁剪后可以降低体积、减少启动时间并提升稳定性。

## 12. 什么情况下适合用轮询

当事件频率稳定、实现简单性优先，或硬件条件受限时，可以考虑轮询。但对于高效实时处理，中断通常更合适。
