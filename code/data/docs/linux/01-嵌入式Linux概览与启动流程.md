# 嵌入式 Linux 概览与启动流程

## 1. 什么是嵌入式 Linux

嵌入式 Linux 指运行在专用设备上的 Linux 系统。它通常部署在路由器、工业控制器、智能终端、开发板和物联网设备上。

与桌面 Linux 相比，嵌入式 Linux 更强调：

- 资源受限：CPU、内存、存储空间都更紧张
- 功能聚焦：只保留设备实际需要的组件
- 启动稳定：系统必须在固定时间内可靠启动
- 硬件适配：需要针对特定芯片、外设和驱动做裁剪

## 2. 典型系统组成

一个典型的嵌入式 Linux 系统通常包括：

1. Bootloader
2. Linux Kernel
3. Root Filesystem
4. 应用程序
5. 配置文件与设备节点

Bootloader 负责初始化基础硬件并加载内核；内核负责进程、内存、驱动和文件系统管理；根文件系统提供运行时环境；应用程序完成具体业务功能。

## 3. 启动流程

一个典型的启动流程如下：

1. 上电复位
2. CPU 从固定地址取第一条指令
3. Boot ROM 或一级引导程序启动
4. Bootloader 初始化 DDR、串口、时钟等基础硬件
5. Bootloader 加载 Linux 内核和设备树
6. 内核解压并启动
7. 内核挂载根文件系统
8. 执行第一个用户态进程，例如 `init` 或 `systemd`
9. 启动系统服务和应用程序

## 4. Bootloader 的作用

Bootloader 常见实现是 U-Boot。它主要负责：

- 初始化最基本的硬件环境
- 提供下载、烧录、调试命令
- 设置内核启动参数
- 加载内核、设备树、根文件系统镜像

常见启动参数示例：

```text
console=ttyS0,115200 root=/dev/mmcblk0p2 rw rootwait
```

其中：

- `console=ttyS0,115200` 指定串口控制台
- `root=/dev/mmcblk0p2` 指定根文件系统分区
- `rw` 表示以可写方式挂载
- `rootwait` 表示等待根设备准备完成

## 5. 设备树的作用

设备树用于描述硬件信息，例如：

- CPU 和内存
- UART、I2C、SPI、GPIO
- 中断号
- 时钟资源
- 外设挂载关系

内核通过设备树在启动时识别硬件，匹配对应驱动。

## 6. 常见面试问答

### 问：Bootloader 和 Linux 内核的边界是什么？

答：Bootloader 负责最小硬件初始化和加载内核；内核接手后负责完整的硬件管理、进程调度、内存管理和驱动框架。

### 问：为什么嵌入式 Linux 往往需要定制根文件系统？

答：因为设备资源有限，而且业务功能单一，不需要完整桌面系统，所以通常只保留必要命令、库、配置和应用程序。

### 问：设备树和驱动是什么关系？

答：设备树描述“板子上有什么硬件”，驱动负责“如何操作这些硬件”。内核通过兼容字符串把二者匹配起来。
