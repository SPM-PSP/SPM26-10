# 文件系统与常用目录

## 1. Linux 文件系统的基本思想

Linux 中“万物皆文件”是一个重要理念。普通文件、目录、设备、管道、套接字等都以文件抽象来访问。

文件系统的作用包括：

- 组织和存储数据
- 提供统一访问接口
- 管理权限和元数据
- 支持挂载不同存储设备

## 2. 根文件系统

根文件系统通常记为 `/`，它是整个目录树的起点。

系统启动后，内核需要先挂载根文件系统，随后用户态程序才能正常运行。

在嵌入式 Linux 中，根文件系统可能来自：

- Flash 分区
- SD 卡
- NFS 网络文件系统
- initramfs

## 3. 常见目录含义

- `/bin`：基本命令
- `/sbin`：系统管理命令
- `/etc`：配置文件
- `/dev`：设备文件
- `/proc`：进程和内核信息的伪文件系统
- `/sys`：设备和驱动模型信息
- `/lib`：共享库
- `/usr`：用户级程序和资源
- `/tmp`：临时文件
- `/var`：日志、缓存、运行时数据

## 4. 挂载的概念

挂载就是把一个文件系统接入当前目录树的过程。

例如：

```bash
mount /dev/mmcblk0p2 /mnt
```

表示把某个块设备对应的文件系统挂载到 `/mnt`。

## 5. 虚拟文件系统

Linux 内核中常见两类虚拟文件系统：

### `/proc`

提供进程和内核状态信息，例如：

- `/proc/cpuinfo`
- `/proc/meminfo`
- `/proc/<pid>/status`

### `/sys`

用于展示设备模型、驱动和总线信息，例如：

- `/sys/class`
- `/sys/bus`
- `/sys/devices`

## 6. 嵌入式场景中的常见文件系统

- ext4：通用块设备文件系统
- squashfs：只读压缩文件系统
- jffs2：适合 NOR Flash
- ubifs：适合 NAND Flash
- tmpfs：基于内存的临时文件系统

## 7. 常见面试问答

### 问：为什么 `/proc` 和 `/sys` 不是普通磁盘文件？

答：它们是内核动态生成的虚拟文件系统，目的是把内核状态和设备信息以文件接口暴露给用户空间。

### 问：根文件系统和普通数据分区的区别是什么？

答：根文件系统是系统启动后最先需要的运行环境，包含基本命令、库和配置；普通数据分区主要用于业务数据存储。

### 问：为什么嵌入式系统常用只读根文件系统？

答：只读文件系统更稳定，也能减少 Flash 写入次数，适合固化系统镜像。
