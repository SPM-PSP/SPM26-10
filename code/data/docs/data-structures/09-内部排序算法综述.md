# 内部排序算法综述

## 1. 排序的定义

排序是把一组记录按照关键字的大小关系重新排列成有序序列的过程。

常见目标包括：

- 从小到大
- 从大到小

## 2. 排序算法分类

常见内部排序算法包括：

- 插入排序
- 交换排序
- 选择排序
- 归并排序
- 快速排序
- 堆排序

## 3. 插入排序

基本思想是把待排序元素逐步插入到前面已经有序的序列中。

特点：

- 实现简单
- 对近乎有序序列效果较好
- 平均时间复杂度通常为 `O(n^2)`

## 4. 冒泡排序

通过相邻元素比较和交换，把较大元素逐步“冒”到后面。

特点：

- 易理解
- 实际效率不高

## 5. 选择排序

每一轮选择最小元素放到前面。

特点：

- 比较次数相对稳定
- 移动次数较少

## 6. 快速排序

通过选择枢轴，把序列划分成左右两部分，再递归排序。

特点：

- 平均性能通常很好
- 最坏时间复杂度可能为 `O(n^2)`
- 常被广泛使用

## 7. 归并排序

采用分治思想，把序列不断拆分，再有序合并。

特点：

- 时间复杂度稳定为 `O(n log n)`
- 通常需要额外辅助空间

## 8. 堆排序

利用堆这种数据结构完成排序。

特点：

- 时间复杂度为 `O(n log n)`
- 原地排序

## 9. 稳定性

如果两个关键字相等的记录在排序前后相对次序不变，则称排序算法稳定。

例如：

- 插入排序通常稳定
- 冒泡排序通常稳定
- 快速排序通常不稳定
- 堆排序通常不稳定

## 10. 常见面试问答

### 问：为什么快速排序通常很快？

答：因为平均情况下划分较均匀，而且局部性较好，实际实现效率往往很高。

### 问：归并排序和快速排序怎么选？

答：归并排序时间复杂度更稳定，快速排序平均性能通常更好但最坏情况较差。

### 问：稳定排序有什么意义？

答：当记录除了主关键字外还有其他信息时，稳定性有助于保留原有相对顺序。
