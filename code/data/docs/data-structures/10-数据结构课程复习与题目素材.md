# 数据结构课程复习与题目素材

## 1. 课程复习主线

复习数据结构时，建议按以下顺序梳理：

1. 数据结构基本概念
2. 线性表
3. 栈与队列
4. 串与数组
5. 树与二叉树
6. 图
7. 查找
8. 排序

## 2. 高频知识点汇总

### 线性表

- 顺序表和链表的区别
- 插入删除复杂度
- 随机访问能力

### 栈与队列

- 栈的后进先出
- 队列的先进先出
- 循环队列的判空判满

### 树

- 二叉树定义
- 完全二叉树性质
- 先中后序遍历
- 层次遍历

### 图

- 邻接矩阵与邻接表
- DFS 与 BFS
- 图的连通性

### 查找与排序

- 折半查找前提
- 散列表冲突处理
- 常见排序算法复杂度与稳定性

## 4. 判断与选择题素材

- 顺序表一定适合频繁插入和删除。
- 链表支持按下标 `O(1)` 随机访问。
- 栈属于先进先出结构。
- 队列属于先进先出结构。
- 完全二叉树适合顺序存储。
- BFS 常借助队列实现。
- 二分查找要求查找表有序。
- 快速排序一定是稳定排序。

## 6. 常见问答

### 问：为什么数据结构课程强调“结构决定效率”？

答：因为不同数据组织方式会直接影响查找、插入、删除和遍历等操作的时间与空间开销。

### 问：为什么课程里总强调复杂度而不是单次运行时间？

答：因为复杂度更能反映算法在规模扩大时的增长趋势，具有更普适的比较意义。

### 问：为什么图遍历比树遍历更复杂？

答：因为图可能存在回路，遍历时通常需要额外标记访问状态，防止重复访问和无限循环。
