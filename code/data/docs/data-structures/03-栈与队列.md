# 栈与队列

## 1. 栈的定义

栈是只允许在一端进行插入和删除操作的线性表。

这一端称为栈顶，另一端称为栈底。

栈的特点是：

- 后进先出
- 英文常写作 LIFO

## 2. 栈的基本操作

常见操作包括：

- `Push`：入栈
- `Pop`：出栈
- `GetTop`：取栈顶元素
- 判空

## 3. 栈的应用

栈的典型应用包括：

- 括号匹配
- 表达式求值
- 函数调用栈
- 深度优先搜索
- 递归实现

## 4. 队列的定义

队列是只允许在一端插入、另一端删除的线性表。

- 插入的一端称为队尾
- 删除的一端称为队头

队列的特点是：

- 先进先出
- 英文常写作 FIFO

## 5. 队列的基本操作

常见操作包括：

- `EnQueue`：入队
- `DeQueue`：出队
- `GetHead`：取队头元素
- 判空

## 6. 循环队列

普通顺序队列如果仅靠下标前移，可能出现“假溢出”。

循环队列通过把存储空间逻辑上首尾相连，可以更充分利用数组空间。

在循环队列中，常用取模运算更新下标。

## 7. 栈与队列的典型区别

### 栈

- 后进先出
- 更适合处理递归、回溯和逆序问题

### 队列

- 先进先出
- 更适合处理排队、层次遍历和调度问题

## 8. 双端队列

双端队列允许在两端插入和删除。

它兼具一定的栈和队列特性，但并不完全等价于二者。

## 9. 常见面试问答

### 问：栈和递归有什么关系？

答：递归调用本质上依赖系统调用栈保存函数现场，所以递归和栈密切相关。

### 问：为什么循环队列能解决假溢出？

答：因为删除后的空间可以被重新利用，而不是像普通顺序队列那样浪费在数组前部。

### 问：层次遍历二叉树通常用栈还是队列？

答：通常用队列，因为层次遍历要求按进入顺序逐层处理结点。
