# 串、数组与广义表基础

## 1. 串的定义

串是由零个或多个字符组成的有限序列。

通常记作：

```text
S = "abcde"
```

串和一般线性表的区别在于：

- 串中的元素通常是字符
- 很多操作面向整体子串处理，而不是单个元素

## 2. 串的常见操作

常见操作包括：

- 求串长
- 串连接
- 求子串
- 比较
- 模式匹配

## 3. 模式匹配

模式匹配是串处理中的核心问题之一，即在主串中寻找模式串出现的位置。

常见方法：

- 朴素匹配
- KMP 算法

## 4. 数组的特点

数组是相同类型元素的有序集合，通常支持按下标随机访问。

数组特点：

- 元素类型相同
- 存储通常连续
- 支持多维结构

## 5. 特殊矩阵的压缩存储

在二维数组中，某些矩阵元素有规律，例如：

- 对称矩阵
- 三角矩阵
- 稀疏矩阵

若仍按普通二维数组存储，会浪费大量空间，因此常采用压缩存储。

## 6. 稀疏矩阵

稀疏矩阵中绝大多数元素为零，非零元素很少。

常见存储方式包括：

- 三元组表
- 十字链表

## 7. 广义表

广义表是线性表的推广，元素既可以是原子，也可以是子表。

例如：

```text
(a, (b, c), d)
```

广义表能够表示更复杂的层次结构。

## 8. 常见考试问答

### 问：串和普通线性表最大的区别是什么？

答：串通常以整体字符串操作为主，很多经典算法如模式匹配都围绕“子串”展开。

### 问：为什么要研究稀疏矩阵压缩存储？

答：因为很多实际矩阵非零元素很少，普通二维存储会浪费大量空间。

### 问：广义表的意义是什么？

答：它能描述嵌套层次更复杂的数据结构，是线性表的扩展。
