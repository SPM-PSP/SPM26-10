# 二叉树遍历与线索化

## 1. 为什么要遍历二叉树

遍历是按某种规则访问树中所有结点且每个结点仅访问一次的过程。

遍历是树结构处理中最基础的操作之一。

## 2. 深度优先遍历

二叉树常见深度优先遍历包括：

- 先序遍历
- 中序遍历
- 后序遍历

### 先序遍历

访问顺序：

1. 根
2. 左子树
3. 右子树

### 中序遍历

访问顺序：

1. 左子树
2. 根
3. 右子树

### 后序遍历

访问顺序：

1. 左子树
2. 右子树
3. 根

## 3. 层次遍历

层次遍历按层从上到下、从左到右访问结点。

实现时通常借助队列。

## 4. 递归与非递归实现

### 递归实现

- 思路清晰
- 代码简洁

### 非递归实现

- 常借助栈
- 更有助于理解遍历的底层机制

## 5. 遍历结果的意义

在不同场景中，遍历结果具有不同作用：

- 先序：适合复制或输出树结构
- 中序：在二叉排序树中得到有序序列
- 后序：适合删除或释放整棵树
- 层次：适合按层分析结构

## 6. 线索二叉树

普通二叉链表中，很多空指针域没有被利用。

线索二叉树利用这些空指针保存遍历前驱或后继信息，从而提高遍历效率。

常见类型包括：

- 先序线索二叉树
- 中序线索二叉树
- 后序线索二叉树

## 7. 常见考试问答

### 问：二叉排序树中序遍历为什么是有序的？

答：因为其左子树值都小于根，右子树值都大于根，中序遍历恰好按左、根、右访问。

### 问：层次遍历为什么常借助队列？

答：因为队列先进先出的特性适合逐层按进入顺序处理结点。

### 问：线索化的核心目的是什麽？

答：利用原本空闲的指针域，保存遍历关系，减少遍历时反复回溯的代价。
