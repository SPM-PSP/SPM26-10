# 树与二叉树基础

## 1. 树的定义

树是 `n` 个结点的有限集合。

树的特点：

- 有且仅有一个根结点
- 其余结点可分为若干互不相交的子树

树是一种典型的层次结构。

## 2. 常见术语

树中常见术语包括：

- 根结点
- 双亲结点
- 孩子结点
- 兄弟结点
- 叶子结点
- 结点的度
- 树的度
- 树的高度

## 3. 二叉树的定义

二叉树是每个结点最多只有两个孩子的树结构。

这两个孩子通常区分为：

- 左孩子
- 右孩子

二叉树与一般树不同，它强调左右次序不能随意交换。

## 4. 特殊二叉树

### 满二叉树

每层结点都达到最大数量。

### 完全二叉树

除最后一层外都满，最后一层结点从左到右连续排列。

### 二叉排序树

左子树结点值小于根，右子树结点值大于根。

## 5. 二叉树的性质

一些常见性质：

- 第 `i` 层最多有 `2^(i-1)` 个结点
- 高度为 `h` 的二叉树最多有 `2^h - 1` 个结点
- 完全二叉树适合顺序存储

## 6. 二叉树的存储方式

常见存储方式包括：

- 顺序存储
- 链式存储

顺序存储通常适合完全二叉树；一般二叉树更常用链式结构。

## 7. 常见面试问答

### 问：树和图最主要的区别是什么？

答：树是连通且无环的层次结构，而图的关系更一般，可以有环，也不一定有唯一根。

### 问：为什么完全二叉树适合顺序存储？

答：因为结点分布比较紧凑，不容易浪费数组空间。

### 问：二叉树的左右子树能交换吗？

答：在抽象定义上左右子树有顺序含义，交换后通常视为不同的二叉树。
