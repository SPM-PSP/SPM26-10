# 线性表、顺序表与链表

## 1. 线性表的定义

线性表是具有相同数据类型的 `n` 个数据元素的有限序列。

线性表的特点是：

- 元素类型相同
- 除第一个和最后一个元素外，每个元素有且仅有一个直接前驱和一个直接后继

## 2. 线性表的基本操作

常见基本操作包括：

- 初始化
- 插入
- 删除
- 按位查找
- 按值查找
- 求长度
- 判空

## 3. 顺序表

顺序表是线性表的顺序存储实现，元素在内存中连续存放。

### 优点

- 支持随机访问
- 按下标查找速度快
- 存储密度高

### 缺点

- 插入和删除可能需要移动大量元素
- 容量通常需要预先分配或扩容

## 4. 顺序表的时间复杂度

### 按位查找

- 时间复杂度：`O(1)`

### 按值查找

- 平均时间复杂度：`O(n)`

### 插入和删除

- 平均时间复杂度：`O(n)`

## 5. 链表

链表是线性表的链式存储实现，元素存储位置可以不连续，通过指针连接。

常见链表包括：

- 单链表
- 双链表
- 循环链表

## 6. 单链表

单链表中每个结点通常包含：

- 数据域
- 指针域

指针域指向下一个结点。

### 优点

- 插入删除方便
- 不要求连续存储空间

### 缺点

- 不支持随机访问
- 查找某个位置需要从头遍历

## 7. 顺序表与链表比较

### 顺序表适合

- 查找频繁
- 插入删除较少
- 需要按下标随机访问

### 链表适合

- 插入删除频繁
- 元素数量变化较大
- 不强调随机访问

## 8. 常见考试问答

### 问：顺序表为什么查找快？

答：因为元素连续存储，知道首地址后可以按下标直接计算目标元素位置。

### 问：链表插入删除为什么方便？

答：因为通常只需要修改前后结点指针，而不必整体移动大量元素。

### 问：链表一定比顺序表省空间吗？

答：不一定。链表每个结点要额外存指针，顺序表虽然可能预留容量，但单个元素存储密度更高。
