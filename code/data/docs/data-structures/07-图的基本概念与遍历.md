# 图的基本概念与遍历

## 1. 图的定义

图由顶点集合和边集合组成，用于表示“多对多”关系。

一般记作：

```text
G = (V, E)
```

其中：

- `V` 表示顶点集合
- `E` 表示边集合

## 2. 图与树的区别

图比树更一般，主要区别包括：

- 图可以有环
- 图不一定有根
- 图中一个结点可以与多个结点互相关联

## 3. 图的分类

### 无向图

边没有方向。

### 有向图

边有方向。

### 带权图

边上带有权值，例如距离、成本、时间等。

## 4. 图的存储结构

常见存储方式包括：

- 邻接矩阵
- 邻接表

### 邻接矩阵

适合边较多的稠密图。

### 邻接表

适合边较少的稀疏图。

## 5. 图的遍历

图的遍历是访问所有顶点的过程。

常见方法：

- 深度优先搜索 DFS
- 广度优先搜索 BFS

## 6. DFS

DFS 尽可能沿一条路径向深处搜索，再回溯。

特点：

- 常借助递归或栈
- 适合求连通分量、拓扑相关问题、回溯问题

## 7. BFS

BFS 从起始顶点开始，按距离一层一层扩展。

特点：

- 常借助队列
- 适合无权图最短路径问题

## 8. 连通性

### 无向图

若任意两个顶点之间都有路径，则称图连通。

### 有向图

若任意两个顶点相互可达，则称强连通。

## 9. 常见考试问答

### 问：邻接矩阵和邻接表怎么选？

答：稠密图通常更适合邻接矩阵，稀疏图通常更适合邻接表。

### 问：BFS 和 DFS 最大区别是什么？

答：BFS 是按层扩展，DFS 是沿路径尽量向深处探索。

### 问：无权图求最短路径通常优先用什么？

答：通常优先用 BFS。
