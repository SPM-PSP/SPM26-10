# 数据库原理复习与题目素材

## 1. 课程复习主线
复习数据库原理时，建议按以下主线组织：
- 数据库系统概论
- 关系模型
- SQL 查询
- 数据库设计
- 范式与规范化
- 事务与并发控制
- 恢复技术
- 索引与优化
- 安全性与完整性

## 2. 高频简答题素材
### 题目 1
数据库系统相较于文件系统有哪些优势？

参考要点：
- 数据共享性更强
- 冗余更低
- 独立性更高
- 有统一安全性、完整性、并发和恢复机制

### 题目 2
为什么数据库系统要采用三级模式结构？

参考要点：
- 支持不同层次的数据抽象
- 实现逻辑独立性和物理独立性
- 便于应用和存储分离

### 题目 3
什么是事务的 ACID 特性？

参考要点：
- 原子性
- 一致性
- 隔离性
- 持久性

## 3. 范式题素材
给定一个未规范化关系，分析其函数依赖，判断属于哪一范式，并提出分解方案。

常用答题步骤：
1. 找候选码
2. 找部分依赖
3. 找传递依赖
4. 拆分关系

## 4. SQL 题素材
### 查询类
- 查询所有学生姓名
- 查询选修数据库课程的学生
- 查询平均成绩最高的课程

### 统计类
- 统计每门课程选课人数
- 统计每个专业平均成绩

### 连接类
- 查询学生、课程和成绩的联合信息

## 5. 并发控制题素材
### 题目
说明脏读、不可重复读和幻读的区别。

参考要点：
- 脏读：读未提交数据
- 不可重复读：同一行前后两次读不同
- 幻读：满足条件的记录集合前后不同

## 6. 恢复技术题素材
### 题目
说明 Undo 和 Redo 的含义及作用。

参考要点：
- Undo 撤销未完成事务
- Redo 重做已提交但未落盘操作

## 7. 索引优化题素材
### 题目
为什么索引不是越多越好？

参考要点：
- 占用额外存储
- 插入更新删除成本增加
- 优化器未必都能使用

## 8. 教学与出题建议
自动出题时可按以下维度设计：
- 概念辨析题
- SQL 编写题
- 数据库设计题
- 范式分析题
- 并发与恢复分析题

## 9. 知识图谱式总结
### 理论基础
数据库系统、三级模式、数据独立性

### 模型与设计
关系模型、ER 图、范式

### 语言与实现
SQL、约束、视图、索引

### 管理机制
事务、并发、恢复、安全

## 10. 复习提醒
数据库课程既有理论，也有实践。复习时最好同步做两类训练：
- 理论问答：概念、原理、比较
- 实践操作：SQL、表设计、约束与索引分析
