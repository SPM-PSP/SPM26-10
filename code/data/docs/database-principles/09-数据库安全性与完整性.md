# 数据库安全性与完整性

## 1. 数据库安全性的含义
数据库安全性指保护数据库免受非法使用、泄露、破坏和误操作的能力。

## 2. 常见安全威胁
- 非授权访问
- 数据泄露
- 恶意篡改
- 权限滥用
- SQL 注入

## 3. 用户与权限管理
数据库系统通常通过用户、角色和权限控制不同主体的访问能力。

常见权限：
- SELECT
- INSERT
- UPDATE
- DELETE
- CREATE
- DROP

## 4. 授权与回收
### 授权
```sql
GRANT SELECT, INSERT ON Student TO user1;
```

### 回收
```sql
REVOKE INSERT ON Student FROM user1;
```

## 5. 视图与安全
视图可以为不同用户提供不同的数据视图，从而起到一定的数据隔离作用。

## 6. 数据完整性
完整性强调数据必须满足预先定义的业务规则。

数据库完整性常见类型：
- 实体完整性
- 参照完整性
- 用户定义完整性

## 7. 约束机制
常见约束：
- PRIMARY KEY
- FOREIGN KEY
- NOT NULL
- UNIQUE
- CHECK
- DEFAULT

## 8. 触发器
触发器是在特定事件发生时自动执行的一段数据库程序。

用途：
- 自动校验
- 自动记录日志
- 自动维护派生数据

## 9. 审计与日志
数据库审计用于记录谁在何时对哪些数据进行了哪些操作。

## 10. 学习重点
- 安全性与完整性区别
- 视图和权限管理的作用
- 常见约束类型及使用场景
