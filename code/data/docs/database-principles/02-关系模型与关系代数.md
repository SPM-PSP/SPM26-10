# 关系模型与关系代数

## 1. 关系模型基础
关系模型用二维表表示数据。每一张表称为一个关系，表中的一行对应一个元组，一列对应一个属性。

## 2. 基本术语
- 关系：一张二维表
- 元组：表中的一行
- 属性：表中的一列
- 域：属性允许取值的集合
- 候选码：能唯一标识元组的最小属性集
- 主码：从候选码中选定的一个
- 外码：在一个关系中引用另一个关系主码的属性

## 3. 关系的性质
- 行列顺序无关
- 属性名不能重复
- 元组不可再分
- 不允许完全相同的元组重复出现

## 4. 关系模式
关系模式可表示为：

`关系名(属性1, 属性2, 属性3, ...)`

例如：

`Student(Sno, Sname, Major, Age)`

## 5. 关系完整性
### 实体完整性
主码不能为空，也不能重复。

### 参照完整性
外码要么为空，要么引用被参照关系中存在的主码值。

### 用户定义完整性
根据具体业务场景设置额外约束。

## 6. 关系运算
关系模型中常见运算包括：
- 选择
- 投影
- 并
- 差
- 笛卡尔积
- 连接
- 除法

## 7. 选择与投影
### 选择
从关系中选出满足条件的元组。

记作：

`σ条件(关系)`

### 投影
从关系中选出若干属性列。

记作：

`π属性列表(关系)`

## 8. 连接
连接用于从多个关系中提取相关联的数据。

### 等值连接
按某些属性值相等进行连接。

### 自然连接
在等值连接基础上，去掉重复属性列。

## 9. 关系代数的意义
关系代数是关系数据库查询理论基础，也是理解 SQL 查询逻辑的重要工具。

## 10. 常见教学例题
### 学生选课场景
设有：
- `Student(Sno, Sname, Class)`
- `Course(Cno, Cname, Credit)`
- `SC(Sno, Cno, Grade)`

问题示例：
- 查询所有学生姓名
- 查询选修了数据库课程的学生姓名
- 查询成绩大于 90 的学生学号与课程号
