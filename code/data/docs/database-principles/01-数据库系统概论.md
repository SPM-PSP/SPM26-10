# 数据库系统概论

## 1. 数据库的基本概念
数据库是长期存储在计算机中的、有组织的、可共享的大量数据集合。数据库的目标是高效存储数据并支持安全、可靠、方便的数据访问。

## 2. 数据库系统的组成
数据库系统通常由以下部分组成：
- 数据库
- 数据库管理系统 DBMS
- 应用程序
- 数据库管理员 DBA
- 用户

其中，DBMS 是数据库系统的核心软件，负责定义、操纵、维护和控制数据库。

## 3. 数据管理技术的发展
### 人工管理阶段
- 数据不保存或保存方式原始
- 程序与数据高度耦合
- 数据共享程度极低

### 文件系统阶段
- 数据开始长期保存
- 通过文件组织数据
- 共享性增强，但冗余和不一致问题明显

### 数据库系统阶段
- 数据结构化
- 数据共享程度高
- 数据独立性增强
- 统一控制数据安全性和完整性

## 4. 数据库的特点
- 数据结构化
- 数据共享性高
- 冗余度低
- 数据独立性高
- 统一管理和控制

## 5. 数据库管理系统的主要功能
- 数据定义功能
- 数据操纵功能
- 数据库运行管理
- 数据组织、存储和管理
- 数据库恢复
- 并发控制
- 安全性控制
- 完整性控制

## 6. 数据独立性
### 物理独立性
修改数据的物理存储方式时，应用程序不需要改变。

### 逻辑独立性
修改数据的逻辑结构时，应用程序尽量不需要改变。

数据独立性是数据库系统优于文件系统的重要标志。

## 7. 数据模型
数据模型是数据库中用于描述数据、数据关系和数据约束的工具。

常见数据模型：
- 层次模型
- 网状模型
- 关系模型

现代教学和实际应用中，关系模型最常见。

## 8. 数据库系统三级模式结构
数据库系统通常采用三级模式结构：
- 外模式
- 模式
- 内模式

### 外模式
面向用户或应用程序，是局部数据视图。

### 模式
数据库中全体数据的逻辑结构和特征描述。

### 内模式
数据在物理存储层面的组织方式。

## 9. 两级映像
- 外模式/模式映像
- 模式/内模式映像

两级映像是实现数据独立性的基础。

## 10. 学习重点

- 数据库系统的组成
- 数据独立性的含义
- 三级模式结构及两级映像
