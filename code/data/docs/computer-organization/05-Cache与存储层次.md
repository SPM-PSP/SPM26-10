# Cache 与存储层次

## 1. 为什么需要 Cache

CPU 速度远高于主存速度，如果每次取指或取数都直接访问主存，会严重拖慢系统性能。

Cache 的作用就是缓解 CPU 与主存之间的速度差距。

## 2. Cache 的基本思想

Cache 利用程序访问的局部性原理：

- 时间局部性
- 空间局部性

把近期常用或邻近的数据放入高速缓存中，CPU 下次访问时就可能直接命中 Cache。

## 3. Cache 的几个核心概念

### 命中

CPU 请求的数据就在 Cache 中。

### 未命中

CPU 请求的数据不在 Cache 中，需要到下一级存储器中取。

### 命中率

命中次数占总访问次数的比例。

命中率越高，系统平均访问时间通常越短。

## 4. 地址映射方式

主存块与 Cache 行之间常见映射方式包括：

- 直接映射
- 全相联映射
- 组相联映射

### 直接映射

每个主存块只能映射到一个固定 Cache 行。

优点：

- 实现简单

缺点：

- 冲突未命中较明显

### 全相联映射

一个主存块可映射到任意 Cache 行。

优点：

- 灵活

缺点：

- 硬件比较复杂

### 组相联映射

折中方案，一个主存块可映射到某组内任意一行。

## 5. 替换算法

当 Cache 对应位置已满时，需要选择一块替换。

常见算法包括：

- FIFO
- LRU
- 随机替换

## 6. 写策略

常见写策略包括：

- 写直达
- 写回

### 写直达

每次写 Cache 同时写主存。

优点：

- 主存数据始终较新

缺点：

- 写主存开销较大

### 写回

先只写 Cache，块被替换时再写回主存。

优点：

- 减少主存写次数

缺点：

- 控制逻辑更复杂

## 7. 常见面试问答

### 问：Cache 为什么有效？

答：因为程序访问具有局部性，近期访问的数据和附近数据很可能再次被访问。

### 问：直接映射为什么容易冲突？

答：因为多个主存块可能只能映射到同一个 Cache 行，彼此会频繁替换。

### 问：写回和写直达的核心区别是什么？

答：区别在于数据写入主存的时机，写直达立即写主存，写回延迟到替换时再写。
