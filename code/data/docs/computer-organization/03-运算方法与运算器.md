# 运算方法与运算器

## 1. 运算器的作用

运算器是计算机中负责完成算术运算和逻辑运算的核心部件。

常见功能包括：

- 加减运算
- 乘除运算
- 与或非异或
- 比较
- 移位

## 2. 运算器的主要组成

运算器通常包括：

- 算术逻辑单元 ALU
- 累加寄存器
- 通用寄存器
- 状态标志寄存器
- 移位器

其中 ALU 是执行具体运算的关键部件。

## 3. 加法器

加法器是运算器中最基本的部件。

### 半加器

完成两个 1 位二进制数相加，但不考虑低位进位。

### 全加器

在半加器基础上增加来自低位的进位输入。

多个全加器级联可构成多位加法器。

## 4. 并行进位与串行进位

### 串行进位

每一位都依赖前一位的进位结果，结构简单，但速度较慢。

### 并行进位

通过额外逻辑提前计算进位，速度更快，但硬件复杂度更高。

## 5. 减法实现

在补码系统中，减法通常可以转换为加法：

```text
A - B = A + (-B)
```

其中 `-B` 用补码表示。

## 6. 乘法与除法基本思想

### 乘法

基本思想类似手工乘法，即移位与加法结合。

### 除法

基本思想类似手工除法，即试商、减法和移位结合。

在课程中常涉及：

- 原码一位乘法
- 补码乘法
- 恢复余数法
- 不恢复余数法

## 7. 溢出问题

运算结果超出机器可表示范围时会发生溢出。

在有符号数加法中，常见判定思路是：

- 两个同号数相加，结果符号变化，则可能溢出

## 8. 常见面试问答

### 问：为什么 ALU 很重要？

答：因为几乎所有算术和逻辑操作最终都要通过 ALU 完成。

### 问：补码减法为什么能转成加法？

答：因为负数在机器中本来就以补码形式存在，加上负数的补码即可实现减法。

### 问：并行进位为什么快？

答：因为它减少了逐位等待前一级进位结果的时间。
