# 指令系统与寻址方式

## 1. 什么是指令系统

指令系统是计算机所能识别和执行的全部指令集合。

它是程序员和硬件之间的重要接口。

## 2. 一条指令通常包含什么

一条机器指令通常由两部分组成：

- 操作码
- 地址码

### 操作码

说明要执行什么操作，例如加法、传送、跳转。

### 地址码

说明操作数在哪里，或者结果放到哪里。

## 3. 指令格式

按地址码个数可分为：

- 零地址指令
- 一地址指令
- 二地址指令
- 三地址指令

地址个数不同，表达能力和指令长度通常也不同。

## 4. 指令系统分类

从实现风格上常见：

- 复杂指令系统 CISC
- 精简指令系统 RISC

### CISC

- 指令种类较多
- 单条指令功能较强

### RISC

- 指令较规整
- 强调简单、高频、易流水化

## 5. 寻址方式

寻址方式研究的是“如何得到操作数地址或操作数本身”。

常见寻址方式包括：

- 立即寻址
- 直接寻址
- 间接寻址
- 寄存器寻址
- 寄存器间接寻址
- 基址寻址
- 变址寻址
- 相对寻址

## 6. 几种典型寻址方式

### 立即寻址

操作数直接写在指令中。

优点：

- 取数快

缺点：

- 可表示数值范围有限

### 直接寻址

地址码字段中直接给出操作数所在主存地址。

### 间接寻址

地址码字段中给出的是一个地址，该地址中再保存真正操作数地址。

### 寄存器寻址

操作数在寄存器中。

### 相对寻址

通常用于转移指令，目标地址 = 当前地址 + 偏移量。

## 7. 常见面试问答

### 问：为什么指令系统设计很重要？

答：因为它直接影响程序表示方式、编译器实现、硬件复杂度和系统性能。

### 问：立即寻址和直接寻址的主要区别是什么？

答：立即寻址中操作数本身就在指令中，直接寻址中给出的是操作数的存储地址。

### 问：相对寻址为什么常用于跳转指令？

答：因为它便于实现位置无关代码，也适合表达相对当前位置的转移范围。
