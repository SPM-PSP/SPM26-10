# 总线与输入输出系统

## 1. 什么是总线

总线是计算机各功能部件之间传送信息的公共通路。

采用总线结构的优点包括：

- 连接方式统一
- 扩展较方便
- 减少复杂连线

## 2. 总线分类

按传输内容常分为：

- 数据总线
- 地址总线
- 控制总线

### 数据总线

用于传输数据，通常是双向的。

### 地址总线

用于指出要访问的存储单元或 I/O 端口，通常是单向的。

### 控制总线

用于传输读写控制、时序和状态信号。

## 3. 总线性能指标

常见性能指标包括：

- 总线宽度
- 总线时钟频率
- 总线带宽

总线带宽反映单位时间内可传输的数据量。

## 4. 总线控制方式

多个部件可能都想使用总线，因此需要总线仲裁。

常见仲裁方式包括：

- 集中仲裁
- 分布仲裁

## 5. 输入输出系统的作用

I/O 系统负责实现主机与外部设备之间的数据交换。

其核心任务包括：

- 设备选择
- 数据传输
- 状态管理
- 中断处理

## 6. I/O 编址方式

常见方式包括：

- 统一编址
- 独立编址

### 统一编址

存储器和 I/O 端口共享地址空间。

### 独立编址

I/O 端口拥有独立地址空间。

## 7. 常见面试问答

### 问：为什么数据总线通常是双向的？

答：因为数据既可能从 CPU 送往存储器或设备，也可能从存储器或设备返回 CPU。

### 问：地址总线为什么通常单向？

答：因为地址通常由主控部件发出，用于指定访问目标。

### 问：统一编址和独立编址怎么比较？

答：统一编址更简洁，独立编址更利于区分 I/O 与存储访问，具体取舍依赖体系结构设计。
