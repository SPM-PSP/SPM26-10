# 数据表示与编码

## 1. 为什么要研究数据表示

计算机底层只能直接处理二进制信息，因此字符、整数、浮点数、图像等都必须转换成二进制编码形式。

数据表示研究的核心问题是：

- 信息如何编码
- 编码后如何运算
- 编码范围和精度如何影响结果

## 2. 进位计数制

常见计数制包括：

- 二进制
- 八进制
- 十进制
- 十六进制

在计算机中最基本的是二进制，因为硬件容易用高低电平表示 0 和 1。

## 3. 不同进制的转换

### 十进制转二进制

整数部分通常采用“除 2 取余”法。

### 二进制转十进制

按权展开求和。

### 二进制与十六进制

四位二进制可对应一位十六进制，因此十六进制常用于更紧凑地表示二进制数据。

## 4. 有符号数表示

计算机中有符号整数常见表示方式包括：

- 原码
- 反码
- 补码

### 原码

最高位表示符号，其余位表示数值。

### 反码

正数反码与原码相同，负数反码为符号位不变，其余位按位取反。

### 补码

正数补码与原码相同，负数补码为反码加 1。

补码是现代计算机中最常用的有符号整数表示方式。

## 5. 补码的优势

补码有两个重要优点：

1. 加减法可以统一为加法器实现
2. 零的表示唯一

因此硬件实现更简单。

## 6. 移码

移码通常用于表示浮点数中的阶码。

它的特点是把有符号数整体平移一个偏置值，使结果总为非负。

## 7. 浮点数表示

浮点数通常表示为：

```text
数值 = 尾数 × 基数^阶码
```

在 IEEE 754 标准中，浮点数通常包含：

- 符号位
- 阶码
- 尾数

## 8. 定点数与浮点数

### 定点数

- 小数点位置固定
- 实现简单
- 表示范围有限

### 浮点数

- 小数点位置可变
- 表示范围更大
- 硬件实现更复杂

## 9. 常见面试问答

### 问：为什么计算机中普遍使用补码？

答：因为补码能统一加减法运算逻辑，简化硬件实现。

### 问：浮点数为什么会有精度误差？

答：因为很多十进制小数无法被有限位二进制精确表示，只能近似存储。

### 问：十六进制为什么常见？

答：因为它与二进制转换方便，一位十六进制正好对应四位二进制，更易读。
