# CPU 结构与控制器

## 1. CPU 的组成

CPU 是计算机系统的核心执行部件，通常由以下几部分组成：

- 运算器
- 控制器
- 寄存器组

控制器负责发出控制信号，运算器负责完成算术逻辑操作，寄存器用于高速暂存数据和状态。

## 2. 常见寄存器

CPU 中常见寄存器包括：

- 程序计数器 PC
- 指令寄存器 IR
- 累加器 ACC
- 通用寄存器
- 状态字寄存器 PSW

### 程序计数器 PC

保存下一条待执行指令地址。

### 指令寄存器 IR

保存当前正在执行的指令。

## 3. 指令周期

CPU 执行一条指令所经历的完整过程称为指令周期。

常见阶段包括：

- 取指周期
- 间址周期
- 执行周期
- 中断周期

不是每条指令都一定包含全部阶段，但取指和执行最基本。

## 4. 控制器的作用

控制器根据当前指令内容和机器状态，产生相应控制信号，协调各部件动作。

其作用可以概括为：

- 取指
- 译码
- 发控制信号
- 控制数据流向

## 5. 控制器实现方式

常见控制方式包括：

- 硬布线控制
- 微程序控制

### 硬布线控制

- 控制速度快
- 逻辑较复杂，不易修改

### 微程序控制

- 设计更灵活
- 修改和扩展方便

## 6. 微程序的基本思想

复杂机器指令可拆解为若干更细粒度的微操作。

每条机器指令的执行，本质上是按顺序执行一串微指令。

## 7. 常见面试问答

### 问：PC 和 IR 的区别是什么？

答：PC 指向下一条将要执行的指令地址，IR 保存当前已经取出的指令内容。

### 问：控制器为什么重要？

答：因为它决定“什么时候谁做什么”，没有控制器，各硬件部件无法协调工作。

### 问：硬布线控制和微程序控制怎么比较？

答：硬布线更快但不灵活，微程序更灵活但控制速度通常略慢。
