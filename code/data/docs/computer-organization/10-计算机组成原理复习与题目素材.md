## 4. 判断与选择题素材

- 补码中零有两种表示方法。

- 程序计数器保存当前正在执行指令的内容。
- 数据总线通常是双向总线。
- 流水线主要提高的是系统吞吐率。
- 立即寻址中操作数本身通常在指令中给出。

## 6. 常见问答

### 问：CPU 频率高是不是一定意味着性能更强？

答：不一定。频率只是影响性能的一个因素，Cache、流水线效率、总线和存储系统同样重要。

### 问：为什么补码能统一加减法？

答：因为负数以补码形式参与运算后，加减法可统一使用加法器处理。

### 问：为什么 Cache 对程序性能影响很大？

答：因为 CPU 速度远快于主存，Cache 命中率高低会直接影响平均访存时间。
