# 流水线与性能分析

## 1. 什么是流水线

流水线是一种通过把一条指令执行过程划分为若干阶段，并让多条指令在不同阶段重叠执行来提高吞吐率的技术。

它的核心思想类似工业流水线：

- 每个阶段完成一部分工作
- 多条指令并行推进

## 2. 流水线的目标

流水线的主要目标是提高指令吞吐率，而不是单条指令的执行延迟。

也就是说：

- 单条指令未必更快结束
- 但单位时间内完成的指令数会更多

## 3. 典型流水线阶段

一个简化 CPU 流水线常见阶段包括：

1. 取指
2. 译码
3. 执行
4. 访存
5. 写回

## 4. 流水线带来的问题

流水线不能总是理想运行，常见问题称为“冒险”。

### 结构冒险

多个阶段同时争用同一硬件资源。

### 数据冒险

后一条指令依赖前一条尚未写回的结果。

### 控制冒险

分支跳转导致后续指令取值不确定。

## 5. 常见处理方法

### 结构冒险

- 增加硬件资源
- 合理安排时序

### 数据冒险

- 插入气泡
- 数据前递
- 乱序执行

### 控制冒险

- 分支预测
- 延迟分支

## 6. 性能分析常见指标

常见指标包括：

- 吞吐率
- 加速比
- CPI
- 时钟周期

### CPI

平均每条指令所需时钟周期数。

## 7. 常见面试问答

### 问：流水线是不是让每条指令都更快？

答：不一定。流水线主要提升的是整体吞吐率，不一定缩短单条指令延迟。

### 问：为什么分支指令会影响流水线效率？

答：因为在分支结果明确前，后续该取哪些指令并不确定，可能导致流水线清空或停顿。

### 问：数据前递的作用是什么？

答：在结果尚未正式写回前，直接把中间结果送给后续指令使用，以减少等待。
