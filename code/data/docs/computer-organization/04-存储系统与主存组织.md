# 存储系统与主存组织

## 1. 存储器的作用

存储器用于保存程序、数据和中间结果，是计算机系统中不可缺少的组成部分。

## 2. 存储器分类

按层次可分为：

- 寄存器
- Cache
- 主存
- 外存

按功能和介质也可分为：

- RAM
- ROM
- 磁盘
- 固态硬盘

## 3. 存储系统的层次结构

存储系统通常采用层次结构设计，基本思想是：

- 上层容量小、速度快、价格高
- 下层容量大、速度慢、价格低

这样设计是为了在成本和性能之间取得平衡。

## 4. 主存的基本指标

主存常见性能指标包括：

- 存储容量
- 存取时间
- 存储周期
- 带宽

### 存取时间

从发出访问请求到数据稳定可用所需时间。

### 存储周期

两次连续访问之间最短允许间隔。

## 5. 存储单元与地址

主存由大量存储单元构成，每个单元对应唯一地址。

常见概念：

- 存储字长
- 地址线
- 数据线

若地址总线宽度为 `n` 位，则理论上可寻址 `2^n` 个单元。

## 6. 存储芯片组织

若单片芯片容量不足，往往需要多片组合实现：

- 位扩展
- 字扩展

### 位扩展

增加每个字的位数。

### 字扩展

增加可存储的字数。

## 7. 常见存储器类型

### RAM

- 可读可写
- 掉电丢失数据

### ROM

- 主要用于固化程序或数据
- 掉电后内容通常不丢失

## 8. 常见面试问答

### 问：为什么存储系统要分层？

答：因为单一技术很难同时满足大容量、高速度、低成本三项要求。

### 问：存取时间和存储周期有什么区别？

答：存取时间强调单次访问所需时间，存储周期强调两次访问之间最小间隔。

### 问：地址线宽度和可寻址空间有什么关系？

答：地址线为 `n` 位时，理论上可表示 `2^n` 个不同地址。
