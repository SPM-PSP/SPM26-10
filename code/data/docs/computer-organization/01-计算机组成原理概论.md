# 计算机组成原理概论

## 1. 什么是计算机组成原理

计算机组成原理研究计算机系统内部各部件的组成方式、工作原理以及它们之间的协同机制。

它关注的问题主要包括：

- 计算机由哪些硬件部件组成
- 各部件如何交换信息
- 指令如何执行
- 数据如何存储和传输

## 2. 计算机系统的层次

一个完整的计算机系统通常可以分为：

- 硬件系统
- 软件系统

硬件系统一般包括：

- 运算器
- 控制器
- 存储器
- 输入设备
- 输出设备

软件系统一般包括：

- 操作系统
- 编译器
- 各类应用程序

## 3. 计算机组成与计算机体系结构

两者相关但不完全相同。

### 计算机体系结构

更关注程序员可见的机器属性，例如：

- 指令系统
- 数据类型
- 寄存器
- 存储寻址方式

### 计算机组成

更关注这些机器属性在硬件层面如何实现，例如：

- 控制信号如何产生
- 数据通路如何连接
- 主存与 CPU 如何交互

## 4. 冯·诺依曼结构

冯·诺依曼结构是现代计算机的经典模型，核心特征包括：

1. 计算机由五大部件组成
2. 指令和数据都以二进制形式表示
3. 指令和数据存放在同一个存储器中
4. 程序按顺序执行，特殊情况下可跳转

五大部件通常指：

- 运算器
- 控制器
- 存储器
- 输入设备
- 输出设备

## 5. 现代计算机的基本工作流程

程序运行时，计算机大致经历以下过程：

1. 从主存中取出指令
2. 分析指令类型和操作数位置
3. 取出操作数
4. 执行运算或控制操作
5. 将结果写回寄存器或主存

这个过程不断重复，形成“取指 - 分析 - 执行”循环。

## 6. 计算机性能的影响因素

影响性能的因素很多，常见包括：

- CPU 主频
- 指令执行效率
- 存储器层次结构
- 总线带宽
- 并行度

单纯提高主频并不能解决所有性能问题，存储系统和数据通路同样关键。

## 7. 常见面试问答

### 问：冯·诺依曼结构的核心思想是什么？

答：程序和数据统一存储在主存中，并由控制器按顺序取指执行。

### 问：为什么计算机组成原理是系统课程基础？

答：因为它连接了上层程序设计与下层硬件实现，是理解操作系统、编译原理、体系结构的重要前提。

### 问：计算机五大部件中哪个最重要？

答：它们缺一不可，但控制器和运算器常被合称为 CPU，是系统执行控制的核心。
