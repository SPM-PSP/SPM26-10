# 回溯分支限界与图算法

## 1. 回溯法
回溯法通过深度优先方式搜索解空间树，在发现当前部分解不可能通向合法解时及时回退。

## 2. 回溯法典型应用
- 八皇后问题
- 子集生成
- 全排列
- 图着色

## 3. 分支限界法
分支限界法在搜索过程中利用界函数剪枝，常用于优化问题。

## 4. 图算法基础
图算法在算法课程中占据重要地位。常见问题包括：
- 图遍历
- 最短路径
- 最小生成树
- 拓扑排序
- 关键路径

## 5. 最短路径
- Dijkstra：适用于非负权图
- Floyd：适用于多源最短路径
- Bellman-Ford：可处理负权边

## 6. 最小生成树
- Prim：从点集扩展
- Kruskal：从边集扩展

## 7. 学习重点
- 搜索类算法的剪枝思想
- 不同图算法的适用条件
- 算法复杂度对比
