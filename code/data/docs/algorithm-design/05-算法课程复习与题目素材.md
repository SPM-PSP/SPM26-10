# 算法课程复习与题目素材

## 1. 复习框架
复习算法时建议按“方法论”组织：
- 复杂度分析
- 分治法
- 动态规划
- 贪心算法
- 搜索算法
- 图算法

## 2. 高频简答题
- 什么是最优子结构
- 动态规划和分治法有何区别
- 贪心算法为什么需要正确性证明
- 回溯法与分支限界法区别

## 3. 常见分析题
- 证明某算法复杂度
- 写出状态转移方程
- 比较不同算法适用场景
- 给出某图问题的求解过程

## 4. 出题建议
可按以下维度自动生成试题：
- 概念辨析
- 算法流程填空
- 复杂度计算
- 证明题
- 应用建模题

## 5. 课程价值
算法设计与分析既适合作为问答知识源，也非常适合做：
- 练习生成
- 试卷出题
- 错误点定位
