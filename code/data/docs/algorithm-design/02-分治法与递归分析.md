# 分治法与递归分析

## 1. 分治法思想
分治法把一个大问题分解成若干个规模更小但结构相同的子问题，分别求解后再合并结果。

基本步骤：
- 分解
- 递归求解
- 合并

## 2. 分治法适用条件
- 问题可分解
- 子问题相互独立
- 子问题与原问题形式相同
- 子问题解可合并成原问题解

## 3. 典型例子
- 归并排序
- 快速排序
- 二分查找
- 最近点对问题

## 4. 递归关系
分治算法常通过递归式描述复杂度，例如：
`T(n) = aT(n/b) + f(n)`

## 5. 主定理
主定理可用于分析许多典型分治递归式。学习时要掌握它的适用前提和三种常见情形。

## 6. 归并排序分析
归并排序分为左右两半递归排序，再线性时间合并，因此时间复杂度为 O(n log n)，空间复杂度通常为 O(n)。

## 7. 快速排序分析
快排平均情况下性能很好，但最坏情况下可退化到 O(n^2)。理解基准选择和划分过程非常重要。

## 8. 常见考点
- 写出递归式
- 用主定理求复杂度
- 比较归并排序和快速排序
- 分析递归树
