# 算法设计与分析概论

## 1. 算法的定义
算法是解决某类问题的一组有穷、确定、可执行的步骤。一个好的算法不仅要求正确，还要求效率高、可实现性强。

## 2. 算法的基本特性
- 有穷性
- 确定性
- 可行性
- 有输入
- 有输出

## 3. 算法分析的目标
算法分析主要研究在输入规模增长时，算法的时间消耗和空间消耗如何变化。

## 4. 时间复杂度
时间复杂度用于描述算法执行步骤数量随输入规模增长的趋势。常见复杂度包括：
- O(1)
- O(log n)
- O(n)
- O(n log n)
- O(n^2)
- O(2^n)

## 5. 空间复杂度
空间复杂度描述算法额外占用的存储空间与输入规模之间的关系。

## 6. 最好、最坏与平均情况
评价算法时不能只看某一个输入场景，通常要分析：
- 最好情况
- 最坏情况
- 平均情况

## 7. 算法设计方法总览
后续课程常见方法有：
- 分治法
- 动态规划
- 贪心算法
- 回溯法
- 分支限界法
- 随机化算法

## 8. 学习重点
这门课的核心不是背结论，而是训练：
- 如何建模问题
- 如何选择策略
- 如何证明正确性
- 如何分析复杂度
