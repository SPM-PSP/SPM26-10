# 动态规划与贪心算法

## 1. 动态规划思想
动态规划适用于最优子结构和重叠子问题场景。其核心是把原问题分解为子问题，并保存子问题结果避免重复计算。

## 2. 动态规划设计步骤
- 定义状态
- 写状态转移方程
- 确定边界条件
- 选择自顶向下或自底向上求解

## 3. 经典问题
- 斐波那契数列
- 最长公共子序列
- 最短路径
- 0/1 背包
- 矩阵连乘

## 4. 贪心算法思想
贪心算法每一步都做当前看来最优的选择，希望最终得到全局最优解。

## 5. 贪心适用条件
- 贪心选择性质
- 最优子结构

## 6. 经典贪心问题
- 活动选择
- 哈夫曼编码
- 最小生成树中的 Kruskal 算法
- 单源最短路径中的 Dijkstra 算法（特定条件下）

## 7. 动态规划与贪心区别
- 动态规划会比较大量候选状态，强调全局最优构造。
- 贪心强调局部最优选择，通常结构更简单、效率更高，但不一定适用所有问题。

## 8. 常见题型
- 判断问题适合 DP 还是贪心
- 写状态转移方程
- 证明贪心策略正确性
