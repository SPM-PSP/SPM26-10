# 软件工程概论与生命周期

## 1. 软件工程的目标
软件工程关注如何以工程化方法开发和维护高质量软件，强调过程、规范、协作和可维护性。

## 2. 软件危机
软件危机表现为：
- 项目延期
- 成本失控
- 质量低下
- 维护困难

软件工程正是在应对这些问题的背景下发展起来的。

## 3. 软件生命周期
典型生命周期包括：
- 可行性分析
- 需求分析
- 设计
- 编码
- 测试
- 运行维护

## 4. 过程模型
常见过程模型：
- 瀑布模型
- 原型模型
- 增量模型
- 螺旋模型
- 敏捷开发

## 5. 学习重点
- 软件工程与程序设计区别
- 各生命周期阶段产物
- 过程模型适用场景
